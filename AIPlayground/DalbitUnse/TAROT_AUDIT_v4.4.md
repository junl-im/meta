# 달빛운세 타로 원화·의미 검수 · v4.4

## 기준과 범위

라이더 웨이트 스미스 계열의 22개 메이저·4개 슈트·각 14개 마이너 카드에 있는 인물, 소품, 감정, 행동을 **그림–이름–정·역방향 해석**의 연결 기준으로 삼았습니다. 종교적·점술적 사실 주장이나 과학적 예측 검증이 아닌 **전통적 도상과 창작 해석의 내부 일관성 검수**입니다.

- 메이저 22장, 마이너 56장 = 78장 각각 독립 WebP를 유지했습니다.
- 원화 모음 이미지 시각 검토상, 카드 이름을 정면으로 거스르는 도상이나 명백히 다른 슈트의 원화가 섞인 사례는 발견하지 못했습니다. 그림을 무리하게 전량 교체하지 않았습니다.
- **매달린 사람(The Hanged Man)**에서 인물이 거꾸로 매달린 것은 카드의 정통 도상입니다. 역방향 추첨으로 이미지 전체가 거꾸로 표시되는 현상과 구분합니다. 카드 이미지 렌더링에서는 이미지 회전을 하지 않습니다.
- 마이너 56장의 기존 공통 숫자+슈트 풀이는 카드별 서사를 희석하므로, 각 카드마다 서로 다른 주제·정방향 위로·역방향 주의를 새로 작성했습니다. `dist/data/tarot-minor-readings.json`은 4개 슈트 × 14개 카드 순서입니다.
- `scripts/validate-tarot.mjs`는 78개 이미지 파일 존재, WebP 형식·해시 중복, 원화 목록의 카드 개수와 순서, 고유 풀이 56개의 완결성 및 대표 도상 키워드를 검사합니다.

## 추가 검수 필요

자동 검사만으로 손·얼굴·옷 등의 미세한 이미지 생성 오류를 100% 검증할 수는 없습니다. 교체가 필요한 원화가 확인되면 기존 파일은 보존하고 `-v2.webp` 별도 자산으로 제작 후 명시적으로 매핑합니다. 모든 카드를 임의로 재그리는 방식은 브랜드 일관성과 자료 보존에 불리하므로 사용하지 않습니다.
