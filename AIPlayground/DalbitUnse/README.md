# 달빛운세 · Dalbit Unse

가입과 결제 없이 즐기는 한국어 운세·사주·타로 정적 웹앱입니다. AI 놀이터로 옮겨갈 수 있도록 백엔드와 계정 시스템 없이 HTML/CSS/JavaScript로 구현했습니다.

## 실행

- `dist/index.html`을 정적 웹호스팅의 루트 문서로 설정합니다.
- 로컬에서는 `dist`를 정적 파일 서버로 열면 됩니다. 특별한 빌드나 환경변수가 필요 없습니다.
- 배포와 마찬가지로 모든 계산·카드 선택은 방문자의 브라우저에서 수행됩니다.

## 제공 기능

1. 12띠 선택 / 연도별 간편 띠 찾기. 일·주·월·년·날짜별 고정 시드 해석.
2. 사주 4기둥(년주·월주·일주·시주), 양력·음력(윤달), 12시진, 오행 분포 및 기본 상징 풀이.
3. 클래식 구조의 타로 78장(메이저 22장 + 마이너 56장), 1장/3장, 질문 주제, 카드 섞기·선택·3D 뒤집기, 정방향·역방향 해석. 메이저 22장에는 각각 독립된 판타지 원화를, 마이너 56장에는 슈트별/인물별 전용 삽화와 개별 랭크 표식을 적용합니다. **1장 선택에서는 별도 전체화면 개봉식**(카드 확대→3번 심장박동→서서히 뒤집기→빛과 별 파티클→결과) 및 즉시 건너뛰기를 제공합니다.
4. 현재 연도~3년 뒤 신년운세와 계절별 메시지.
5. PC·모바일 전용 일러스트와 모바일 하단 메뉴, 모션 감소 설정 지원, 결과 복사.
6. HTTPS 환경에서 앱 설치·오프라인 재사용을 지원하는 서비스 워커와 버전별 캐시.

## 데이터와 정확도

- `lunar-javascript`가 전통 달력 계산과 천간·지지 정보를 제공합니다. 절입 시각이나 자시 경계, 출생지 태양시 등을 전문 명리 만세력과 비교할 때는 차이가 발생할 수 있습니다.
- 띠별·신년운세는 날짜·띠별 결정적 해시와 자체 작성한 문구 조합으로 생성됩니다. 같은 날짜·조건이면 같은 내용이 나타납니다. 실증적 예언 데이터가 아닙니다.
- 타로는 78장의 겹치지 않는 덱에서 무작위로 뽑으며 상징 해석은 자체 작성했습니다.
- 서비스는 자기성찰·오락을 위한 것이며 중요한 의료·법률·재정 결정을 대신하지 않습니다.
- 입력한 출생 정보, 이름, 타로 질문을 서버에 저장하거나 전송하지 않습니다. 선택한 띠 번호만 기기의 로컬 저장소에 보관할 수 있습니다.

## 카드 그림 제작 규칙

- SVG 금지. 타로 카드 뒷면/테두리에는 기본 PNG/WebP 원화를 사용하고, 앞면은 고유 일러스트 PNG 원본 아틀라스에서 추출한 WebP를 올립니다.
- 메이저 카드 ID 0~21: `tarot-major-a-0.webp`부터 `tarot-major-d-3.webp`까지 각각 다른 인물·사건 그림을 사용합니다.
- 마이너 카드 56장: 완드/컵/소드/펜타클 각각의 상징 그림을 사용하며, 시종·기사·여왕·왕은 인물별 공통 원화를 추가 사용합니다. 56장 모두 독립적으로 손그린 장면은 아직 아닙니다.
- `tarot-majors-a~d.png`와 `tarot-minors-e.png` 원본 5장을 보존하므로 추후 별도 카드 삽화 추가/교체 작업이 가능합니다.
- 이미지 생성 프롬프트: 3열×2행, 인물·사건·상징 6종을 각각 분리된 칸에 배치, 실제 투명 배경, 월광 남보라·금빛, 손으로 그린 판타지 타로 스타일, 글자·프레임·SVG 금지.

## AI 놀이터 이식 메모

- UI와 계산 로직이 서버 API에 의존하지 않으므로 `dist` 폴더 전체를 다른 웹 앱의 정적 자산 폴더로 복사할 수 있습니다.
- 다른 앱의 레이아웃에 포함할 때는 CSS의 전역 `body`, `h1`, `.brand` 등 선택자가 충돌할 수 있으므로 `#dalbit-root` 네임스페이스 적용을 권장합니다.
- 기존 서비스에 회원 계정·저장·AI 해석 연계를 추가하려면 `app.js`의 각 `init...` 및 `render...` 함수를 모듈로 분리하면 됩니다.
- 동봉 라이브러리의 MIT 저작권 고지는 유지해야 합니다.
- 그림 경로를 바꾸거나 전용 덱을 확장할 때는 `dist/data/tarot-artwork.json`에서 버전 및 원화 매핑을 관리합니다. JSON 요청 실패 시에도 내장 그림 경로가 동작하도록 폴백했습니다.
- PWA 서비스 워커의 스코프는 달빛운세가 호스팅되는 경로로 제한됩니다. AI 놀이터 내부로 편입할 때 기존 서비스 워커와 범위 충돌 여부를 점검하세요.
- 새로운 대형 프레임워크를 무조건 도입하지 않고, 우선 네이티브 JavaScript/JSON/CSS 기반을 모듈화합니다. 장기적으로 Vite+TypeScript 빌드 체계를 도입할 경우에도 최종 결과물은 `dist/`에 유지하도록 설계합니다.
