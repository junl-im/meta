# 달빛운세 · Dalbit Unse

가입과 결제 없이 즐기는 한국어 운세·사주·타로 정적 웹앱입니다. AI 놀이터로 옮겨갈 수 있도록 백엔드와 계정 시스템 없이 HTML/CSS/JavaScript로 구현했습니다.

## 실행

- `dist/index.html`을 정적 웹호스팅의 루트 문서로 설정합니다.
- 로컬에서는 `dist`를 정적 파일 서버로 열면 됩니다. 특별한 빌드나 환경변수가 필요 없습니다.
- 배포와 마찬가지로 모든 계산·카드 선택은 방문자의 브라우저에서 수행됩니다.

## 구성

| 경로 | 역할 |
| --- | --- |
| `dist/index.html` | 반응형 화면/SEO/접근성 구조 |
| `dist/style.css` | 남색·금빛 테마, 타로 3D 카드/애니메이션, 모바일 UI |
| `dist/art.css` | PC·모바일 전용 일러스트 적용 및 이미지 기반 연출 |
| `dist/app.js` | 운세 기간, 12띠, 78장 타로, 사주, 신년 콘텐츠 로직 |
| `dist/assets/lunar.js` | MIT 라이선스 음양력·24절기·간지 계산 라이브러리 |
| `dist/assets/LICENSE-lunar.txt` | 제3자 라이선스 고지 |
| `dist/assets/*.webp` | 서비스에 적용된 압축된 전용 일러스트 7종 |
| `dist/assets/*.png` | 원본 고화질 일러스트 7종과 PNG 파비콘 |

## 제공 기능

1. 12띠 선택 / 연도별 간편 띠 찾기. 일·주·월·년·날짜별 고정 시드 해석.
2. 사주 4기둥(년주·월주·일주·시주), 양력·음력(윤달), 12시진, 오행 분포 및 기본 상징 풀이.
3. 클래식 구조의 타로 78장(메이저 22장 + 마이너 56장), 1장/3장, 질문 주제, 카드 섞기·선택·3D 뒤집기, 정방향·역방향 해석.
4. 현재 연도~3년 뒤 신년운세와 계절별 메시지.
5. 모바일 반응형 UI, 모션 감소 설정 지원, 결과 복사.

## 데이터와 정확도

- `lunar-javascript`가 전통 달력 계산과 천간·지지 정보를 제공합니다. 절입 시각이나 자시 경계, 출생지 태양시 등을 전문 명리 만세력과 비교할 때는 차이가 발생할 수 있습니다.
- 띠별·신년운세는 날짜·띠별 결정적 해시와 자체 작성한 문구 조합으로 생성됩니다. 같은 날짜·조건이면 같은 내용이 나타납니다. 실증적 예언 데이터가 아닙니다.
- 타로는 78장의 겹치지 않는 덱에서 무작위로 뽑으며 상징 해석은 자체 작성했습니다.
- 서비스는 자기성찰·오락을 위한 것이며 중요한 의료·법률·재정 결정을 대신하지 않습니다.
- 입력한 출생 정보, 이름, 타로 질문을 서버에 저장하거나 전송하지 않습니다. 선택한 띠 번호만 기기의 로컬 저장소에 보관할 수 있습니다.

## AI 놀이터 이식 메모

- UI와 계산 로직이 서버 API에 의존하지 않으므로 `dist` 폴더 전체를 다른 웹 앱의 정적 자산 폴더로 복사할 수 있습니다.
- 다른 앱의 레이아웃에 포함할 때는 CSS의 전역 `body`, `h1`, `.brand` 등 선택자가 충돌할 수 있으므로 `#dalbit-root` 네임스페이스 적용을 권장합니다.
- 기존 서비스에 회원 계정·저장·AI 해석 연계를 추가하려면 `app.js`의 각 `init...` 및 `render...` 함수를 모듈로 분리하면 됩니다.
- 동봉 라이브러리의 MIT 저작권 고지는 유지해야 합니다.
