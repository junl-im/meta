# 곰같은여우의 달빛운세 · v4.7

공개형 한국어 운세 웹앱. **첫 화면에만 ‘가입 없이 무료’를 표시**하며, PC·모바일에 각각 맞춘 일러스트와 인터랙션을 사용합니다. 사이트는 AI 놀이터에 통합할 수 있도록 독립 프로젝트로 유지합니다.

## 실행과 빌드

```bash
npm ci
npm run check
npm run build
```

- 최종 사이트 산출물은 `dist/`에 있습니다. HTTPS 정적 호스팅에서 바로 공개할 수 있습니다.
- TypeScript 소스 `src/experience.ts`, `src/modules/`를 Vite로 빌드하면 `dist/experience.js`가 갱신됩니다.
- 기존 운세·타로 엔진 `dist/app.js`는 호환성을 유지하면서 점진적으로 TypeScript로 이전합니다.
- 사주·궁합 입력 정보는 브라우저에서만 처리하고 서버로 전송하지 않습니다.

## 화면 구성

| 메뉴 | 한 화면의 주요 내용 | 세부 입력 방식 |
| --- | --- | --- |
| 홈 | PC·모바일 전용 달빛 원화와 타이틀, 첫 화면에서만 무료 안내 | 메뉴는 상단 및 모바일 하단에서 이동 |
| 띠별운세 | 12띠 선택 → 결과를 한 번에 확인, 오늘·주·월·년·날짜 운세 | 모바일은 선택과 결과를 각각 독립 장면으로 전환, 출생 연도 팝업 |
| 사주풀이 | 사주팔자·오행·일간·십성·지지 관계·대운·세운, 출생정보와 날짜를 결합한 일·주·월·년 운세 | 이름·성별·양력/음력·윤달·생년월일·출생시간 팝업 |
| 타로카드 | 1장/3장 선택, 카드 펼침·반전·빛 효과 | 화면 안의 단계별 카드 리딩 |
| 궁합 | 두 사람의 일간 오행·일지 관계·대운을 결합해 관계를 살피는 결과 | **2명 각각** 이름·성별·양력/음력·윤달·생년월일·출생시간 팝업 |
| 신년운세 | 해·띠 선택, 연간·계절별 흐름 | 화면 안의 간결한 선택 |

화면은 메뉴를 클릭해 전환합니다. 긴 메인 페이지를 아래로 계속 내리지 않습니다. 내용이 길거나 모바일 높이가 낮을 때는 **현재 화면 내부에서만** 스크롤합니다. 데이터 입력은 네이티브 `dialog` 팝업을 사용하고 Esc·달빛형 닫기 버튼으로 닫을 수 있습니다. 홈의 메뉴 중복 버튼은 제거했습니다.

## 디자인과 타로 자산

- 일반 SVG 일러스트를 쓰지 않습니다. 원화는 투명 PNG와 최적화한 WebP, 타로 카드는 장당 별도 WebP입니다.
- 타로는 메이저 아르카나 22장 + 마이너 아르카나 56장, 총 **78개 개별 카드 삽화**를 `dist/data/tarot-artwork.json`에서 매핑합니다.
- `dist/assets/tarot-major-*.webp` 22장과 `dist/assets/tarot-{wands,cups,swords,pentacles}-{a,b}-*.webp` 56장으로 구성합니다.
- PC와 모바일에는 서로 다른 홈 원화 배경, 다른 내비게이션과 카드 레이아웃을 적용합니다. 팝업 확인 버튼·닫기 버튼은 카드 원화에서 가져온 질감과 황금빛 베젤로 통일합니다. `prefers-reduced-motion`을 존중합니다.
- v4.3부터 운세 화면과 팝업의 사각 테두리를 줄이고, 기존 월광·사주·신년 일러스트를 **끝이 투명하게 사라지는 장면 배경**으로 사용합니다. 스크롤바도 밤하늘의 보라·금색 톤으로 맞춥니다.
- 역방향 타로의 해석은 유지하되, 카드 그림 자체는 항상 정상 방향으로 표시하고 **역방향 표식**으로 구분합니다. 35%의 카드가 역방향으로 해석되던 기존 규칙을 유지합니다.
- v4.4부터 **마이너 56장 모두** 장면별 고유한 정방향·역방향 풀이를 `dist/data/tarot-minor-readings.json`으로 분리하여 적용합니다. `node scripts/validate-tarot.mjs`로 78장 매핑, 개별 WebP 원화, 중복 여부, 카드 해석 데이터의 완결성을 점검합니다. 검수 기준은 [검수 기록](TAROT_AUDIT_v4.4.md)을 참고하세요.
- v4.4 팝업은 내용에 맞게 띠 약 370px, 사주 약 490px, 두 사람 궁합 약 674px을 기본 상한으로 사용하며 모바일에서는 현재 화면에 맞춰 폭과 최대 높이를 제한합니다. 긴 입력·결과만 팝업 안에서 스크롤합니다.
- v4.7부터 모바일 타로 결과의 ‘다시 카드 뽑기’·‘결과 복사’는 아래 메뉴 바로 위에 고정해 결과가 길어도 언제든 사용할 수 있습니다. 카드 설명은 원화와 문장을 나란히 보이도록 재배치하고, 다시 뽑으면 새 카드 펼침으로 화면을 이동합니다. 태블릿·PC의 결과 레이아웃은 유지합니다.
- 원본 아틀라스 PNG는 배포 용량을 줄이기 위해 사이트 소스 저장소에는 올리지 않고 별도 원화 백업에 포함합니다.

## 데이터·오디오·오프라인

- 운세·타로·신년·궁합 문구는 `dist/data/*.json`에서 관리합니다. 네트워크 실패 시 엔진 내 안전한 기본 문구를 사용합니다.
- v4.6부터 자체 사주 해석 DB `dist/data/saju-knowledge.json`으로 10일간, 10십성, 12지지, 오행, 4개 생활 영역의 해석을 분리해 관리합니다. 일·주·월·년 및 지정일의 간지는 달력 엔진이 계산하고 해석 문장은 DB와 조합합니다. [근거·확장 가이드](SAJU_KNOWLEDGE_GUIDE.md)를 함께 확인하세요.
- 오픈소스 `lunar-javascript`(MIT)로 양음력과 천간·지지를 계산합니다. `dist/assets/LICENSE-lunar.txt`에 고지가 있습니다.
- 별자리·궁합 점수 및 해석은 자기성찰과 오락을 위한 **상징적 산출**이며 관계·미래를 확정하거나 의료·재정 결정에 사용할 수 없습니다.
- 배경음은 `src/modules/ambient-music.ts`가 브라우저 Web Audio로 직접 합성하는 잔잔한 멜로디입니다. **기본 켜짐**이며, 실제 재생은 브라우저 정책상 첫 터치·클릭·키 입력 이후 시작할 수 있습니다. 헤더의 황금색/은보라색 전용 일러스트 아이콘으로 켜짐과 꺼짐을 구분하며, 사용자가 끈 설정은 보존합니다.
- 결과 읽어주기는 사용자 별도 프로젝트 **소리온의 ‘별하’ 성우** 전용 연동 자리를 유지합니다. 별하가 준비되기 전까지는 사용자가 ON으로 켠 경우 **브라우저의 임시 한국어 음성**을 사용하며, 설치된 음성 목록에서 여성 목소리 이름을 우선 탐색합니다. 기기별 실제 성별·음색은 보장되지 않습니다. 연동 계약은 [별하 연결 문서](SORION_BYEOLHA_CONTRACT.md)에 있습니다.
- `dist/sw.js`는 정적 코드·JSON·그림을 캐시하고, 새로운 버전으로 갱신합니다.
- 모바일 주소창·키보드 때문에 달라지는 실제 표시 영역의 높이는 `src/modules/viewport-fit.ts`에서 Visual Viewport를 이용해 맞춥니다. `src/modules/interaction-guard.ts`가 일반 화면의 우클릭·끌기·텍스트 드래그를 제한하지만 입력칸은 그대로 사용할 수 있게 합니다.

## AI 놀이터 이식

원본 소스의 기준 경로는 GitHub 공개 저장소 `junl-im/meta`의 `AIPlayground/DalbitUnse/`입니다. 이 위치에서 코드를 버전 관리하며, 현재 공개 사이트는 별도 정적 배포본으로 운영합니다. GitHub Pages 배포는 저장소의 Pages 설정을 별도로 확인한 뒤 활성화해야 합니다.

1. `dist/` 정적 앱을 독립 iframe이나 하위 경로로 먼저 넣어 서비스 워커 스코프를 격리합니다.
2. HTML/CSS를 호스트 화면에 직접 삽입한다면 전역 선택자를 프로젝트 고유 루트 이름으로 감싸 충돌을 제거합니다.
3. `dist/data/*.json`, `src/modules`를 필요에 따라 공용 콘텐츠 및 음성 모듈로 교체합니다.
4. 소리온 별하의 실제 SDK/API가 준비된 후 인터페이스와 보안·요금·지연 등을 합의하여 연결합니다.
