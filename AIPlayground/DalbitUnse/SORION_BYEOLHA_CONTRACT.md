# 소리온 별하 성우 · 달빛운세 연결 계약 (v4.6)

## 현재 상태

- 결과 낭독 버튼의 ON/OFF 원본 PNG 완성. 사이트에서는 경량 투명 WebP `dist/assets/voice-on.webp`, `voice-off.webp`를 사용하며 전체 원본은 별도 자산 백업에도 보존.
- 초기 상태 **OFF**. 사용자가 ON으로 바꾸면 결과가 새로 생성될 때에만 낭독 요청.
- 실제 별하 엔진 파일·API 서버 주소는 아직 제공되지 않아 **실제 별하 음성 연결은 대기**.
- 사용자가 ON으로 전환하면 **임시 브라우저 한국어 음성**으로 결과를 낭독합니다. 기기에 설치된 한국어 음성 중 알려진 여성 목소리 이름을 우선하지만, 웹 음성 API에는 공통의 성별 표준 속성이 없어 **모든 기기에서 여성 목소리를 보장할 수는 없습니다**.
- `window.SoriOn.voices.byeolha`가 준비되면 그 엔진을 우선 사용합니다. 별도 외부 유료 TTS 서버 호출이나 비밀 API 키는 사용하지 않습니다.
- 결과 낭독 중에는 배경음 음량을 낮추고 종료 시 원래 음량으로 복귀합니다.
- 모듈 연결 중 오류가 나도 운세/사주/타로 결과를 정상 표시.

## 연결 인터페이스 (최종 소리온 구현에 맞춰 협의 필요)

달빛운세 쪽이 현재 기다리는 브라우저 전역 계약:

```js
window.SoriOn = {
  voices: {
    byeolha: {
      speak: async ({ text, voice, style }) => {
        // text: 보여준 결과 본문만. voice: 'byeolha'. style: 'mystical-gentle'.
      },
      stop: async () => {
        // 새 결과가 생성되거나 음성을 끄거나 메뉴를 바꾸면 이전 낭독 중단.
      }
    }
  }
};
window.dispatchEvent(new Event('sorion:byeolha-ready'));
```

소리온 프로젝트의 실제 API 형태가 확정되면 `src/modules/byeolha-bridge.ts` 어댑터만 수정하고
사주/궁합/타로/신년운세 계산 코드는 그대로 유지하는 구조.

## 호출 조건

1. 사용자가 읽어주기를 명시적으로 ON. 기본 설정은 OFF.
2. 결과 새 생성 또는 갱신 완료.
3. 표시된 결과의 본문 문장만 `DalbitByeolha.read(text)`로 전달.
4. 새 결과 호출 시 `stop()`으로 이전 낭독을 중단한 뒤 새 본문만 재생.
5. OFF 또는 메뉴 이동 시 `stop()` 요청. 브라우저 음성 재생도 즉시 취소.

사주 입력 이름·생년월일 원본 전체를 소리온에 넘기지 않도록 각 화면에서
읽어줄 문장만 구성함. 다만 최종 소리온이 서버 기반이라면 실제 API와 개인정보 처리
정책·동의 플로우를 확인한 뒤 활성화할 것.

## 검증이 남은 항목

- 실제 소리온 성우 엔진의 인터페이스와 인증 방식
- 음성 재생 딜레이·대량 텍스트 분할·중간 취소·네트워크 장애
- 모바일 브라우저의 사용자 제스처 및 소리 재생 권한
- 실제 성우 톤·속도·영롱한 음색 품질
