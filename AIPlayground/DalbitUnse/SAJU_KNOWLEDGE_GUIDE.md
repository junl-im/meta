# 달빛운세 사주 해석 데이터베이스 · v4.6

## 책임 범위

`dist/data/saju-knowledge.json`은 명리학의 천간·지지·십성·오행 분류를 바탕으로 **달빛운세에서 새롭게 작성한 상담 문장 데이터**입니다. 민간 상담사가 사용하는 비공개 데이터베이스를 복제한 것이 아니며 전문가 상담이나 미래 사건의 사실 예측을 보증하지 않습니다. 계산 가능한 전통 체계와 사람마다 달라지는 해석을 명확히 구분합니다.

## 계산과 해석의 분리

1. MIT 라이선스의 `lunar-javascript`가 양력·음력·윤달, 24절기 기준 사주 네 기둥, 십성, 세운·대운을 계산합니다.
2. 사용자의 일간(10개)에 대응하는 장점·주의점·일·관계·금전·돌봄 설명을 선택합니다.
3. 보고 싶은 날의 간지를 다시 계산하고 일간과 비교해 10개의 십성 관계 중 하나를 고릅니다. 주간은 해당 주 월요일, 월간은 해당 날짜의 절기상 월주, 연간은 해당 연도의 대표 세운을 사용합니다.
4. 월지의 대표 오행과 일간의 오행 관계, 서로 다른 지지 사이의 육합·육충만 추가 설명합니다. 같은 지지 2개를 육합·육충으로 오인해서는 안 됩니다.
5. 궁합에서는 두 사람의 일간 오행 관계와 일지 육합·육충을 비교하고, 생년월일과 성별 입력 시 각자의 대운을 별도로 계산합니다. 궁합을 일방적인 점수로 확정하지 않습니다.

## 데이터 무결성

`npm run check`가 10일간, 10십성, 12지지, 육합 6쌍, 육충 6쌍, 40개 분야별 원문, 달력 연동을 확인합니다. 타로 78장 자료·실제 만세력 역법 회귀검사도 기존 스크립트를 통해 함께 검증합니다. 단, 계산의 최종 전문성 검증에는 국내 공인 역서와의 대조, 입춘·윤달·자시 경계·출생 지역별 태양시 처리를 추가해야 합니다.

## 향후 보강할 지식 영역

- 지장간과 통근, 월령·격국·신강신약, 형·파·해·원진, 용신 등의 서로 다른 학파 해석을 **선택 가능한 규칙 세트**로 구현
- 연도별 입춘 경계, 야자시/조자시, 출생 지역 시각 보정 기능 및 참고 역서 출처 표시
- 일·주·월·년별 고유 상담 사례와 현실적인 생활 조언의 문장 품질 검수
- 전문가 감수 기록, 계산 엔진 버전, 규칙의 근거, 한계·불확실성 표기

개인 출생정보는 현재 사용자의 브라우저 안에서만 계산하며 외부 전문 DB API 서버로 전송하지 않습니다. 별하 음성을 서버 API로 연결할 경우에는 보낼 **결과 문장만** 명시적으로 관리하고 보안·개인정보 검토를 먼저 진행합니다.
