# WEBTOON STUDIO 웹 시험판

이 폴더는 WEBTOON STUDIO 웹판 v0.6.106의 AI 없는 브라우저 실행 파일입니다. AI 놀이터 홈의 WEBTOON STUDIO 카드에서 들어오며, `AIPlayground/WebtoonStudio/` 경로에서 다른 도구와 분리되어 작동합니다.

컷·말풍선·텍스트·이미지 기본 편집, 레이어 숨김/잠금, 브라우저 IndexedDB 임시저장, PC판과 호환되는 `.wtoon` 열기·저장, 690px PNG 초안 ZIP을 지원합니다. 원고는 이 정적 사이트의 서버에 업로드되지 않습니다.

말풍선을 선택하면 캔버스의 금빛 점을 드래그해 꼬리를 움직일 수 있습니다. `레이어·속성`의 좌우·상하 좌표로도 조절할 수 있으며, 값은 `.wtoon`과 PNG 초안에 반영됩니다. 모바일 편집 캔버스 상단의 `너비 맞춤`을 누르면 현재 화면 너비에 맞춰지고, 확대 슬라이더로 수동 조절할 수 있습니다. 화면을 회전하거나 크기를 바꾸면 너비 맞춤 상태에서 자동으로 다시 맞춥니다.

말풍선 몸체와 꼬리는 웹 미리보기와 PNG 초안에서 같은 캔버스 경로로 이어 그립니다. 모바일 높이는 동적 화면 높이와 하단 안전 영역을 사용해 메뉴가 브라우저 화면 밖으로 밀리지 않도록 했습니다.

기본·둥근·타원 컷의 화면과 PNG 초안 윤곽을 일치시켰고 이미지 좌우 반전 버튼을 추가했습니다. PNG는 초안입니다. 고급 컷 모양, 고급 식자·그리기, 네이버 최종 파일 제한은 아직 PC판과 동등하지 않습니다. 연재용 출력은 PC판에서 확인하세요. 브라우저 저장소는 기기·브라우저에 묶이므로 중요한 원고는 `.wtoon` 파일로 별도 보관해야 합니다.

소스와 재빌드 명령은 WEBTOON STUDIO 소스 통합본의 `src/web/`, `vite.web.config.ts`, `WEB_README.md`에 있습니다. 정적 파일은 `npm run build:web`으로 생성하고 이 폴더에 복사합니다.
