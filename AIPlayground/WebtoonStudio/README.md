# WEBTOON STUDIO 웹 시험판

PC 편집기와 같은 원고 구조를 사용하며, AI 서버나 계정 없이 브라우저에서 작동합니다. `npm run dev:web`으로 개발 서버를 열고 `npm run build:web`으로 `dist-web/` 정적 파일을 만듭니다. `npm run test:web`은 웹에서 만든 `.wtoon` 파일을 PC판 디코더로 다시 여는 검사를 포함합니다.

현재 가능한 작업: 컷·말풍선·텍스트 추가, 이미지 라이브러리, 컷 이미지 확대·위치, 요소 이동·속성·레이어 숨김/잠금, 되돌리기·다시 실행, IndexedDB 임시저장, PC판과 호환되는 `.wtoon` 열기·저장, 690px PNG 초안 ZIP 출력.

웹판은 초기 시험 단계입니다. 복잡한 컷 모양, 세밀한 식자 효과, 지우개, 폰트 포함 및 네이버 5MB/50MB 최종 출력은 아직 PC판과 동일하게 구현되지 않았습니다. PNG는 최종 업로드 전 PC판에서 비교·확인해야 합니다. 브라우저 임시저장은 해당 브라우저·기기의 저장소에만 남으므로 중요한 작업은 `.wtoon`으로 내려받아 보관하세요. 웹 서버에 원고를 업로드하거나 AI 요청을 보내지 않습니다.

`meta` 저장소에서는 `AIPlayground/WebtoonStudio/`에 정적 웹판을 격리합니다. GitHub Pages/Firebase 빌드 스크립트가 이 폴더만 공개 출력에 복사하도록 연결하고, 놀이터의 진입 링크는 배포 확인 뒤 활성화할 수 있습니다.
