# 곰같은여우의 마음도감

새로운 오리지널 일러스트 기반 MBTI 16유형 × 혈액형 4종 스토리 웹 서비스입니다.

## 경계
- 이 폴더만 프로젝트 소유 범위: `AIPlayground/MaeumDogam/**`.
- 기존 `AIPlayground/DalbitUnse/**`, `ai-cleaner/**`, `OPTION/**`, 루트 `index.html`, GitHub Actions는 수정하지 않습니다.
- 이 브랜치는 자산 수집/설계용이며 기존 AI놀이터 내비게이션이나 실제 사이트 배포에는 연결하지 않습니다.
- 분리된 하위 경로 기준 CSS/JS/캐시/서비스워커 범위로 개발 예정.

## 공식 브랜드
- 타이틀: **곰같은여우의 마음도감**
- 한 줄 소개: **나를 발견하는 가장 재미있는 방법**
- 프로젝트 상태: 시범 기능 구축 v0.4 (제품 출시 전)
- MBTI 유형은 사용자가 직접 지정하거나 독립 개발 탐색 설문으로 확인합니다. 정식 MBTI 검사가 아닙니다.
- 혈액형 해석은 객관적 성격 예측이 아닌 문화적 유머·이야기이며 채점에 사용하지 않습니다.

## 구간 디자인
입구 → 성격마을(16) → 혈액형 소다상점(4) → 관계 다리 → 마음 극장. 배경은 구름/꽃길/물길/다리/장식이 경계 없이 이어집니다. 원본 단일 초대형 이미지 대신 모바일용 레이어드 그림과 DOM 텍스트를 사용합니다.

## 파일 구조(예정)
- `assets/branding/`: 시그니처 곰같은여우 가이드, 국문 워드마크.
- `assets/backgrounds/`: 스크롤 장면별/디바이스별 배경·전경.
- `assets/characters/mbti/`: 16유형 독립 캐릭터, 동일 그림체.
- `assets/characters/blood/`: A/B/O/AB 4개의 스토리 콘셉트.
- `assets/ui/`: 메뉴/버튼/인터랙션 상태 아이콘.
- `assets/decor/`: 배경 간 전환 장식.
- `docs/`: 스타일 가이드, 제작 프롬프트, 검증 계획.
- `ASSET_MANIFEST.json`: 유일한 자산 키/상태/경로 대장.
