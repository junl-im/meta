# 마음도감 v0.4 — 12장면 마음 탐험·상태 복원·접근성 검수

작성일: 2026-10-25 · 개발 브랜치 `feature/maeumdogam-assets-v01` · Draft PR #5

## 변경
- 16유형 직접 선택은 그대로 유지하고, 12개의 짧은 선택 장면을 통한 **오늘의 이야기 유형 추천**을 추가한다.
- 총 4개의 선택 축(E/I, S/N, T/F, J/P)에 각 3문항씩 배치해 동점 없이 16가지 창작 유형 중 하나를 추천한다. 공식 검사·진단·건강 평가가 아니다.
- 문항별 진행률·이전 장면·닫기·키보드 초점·결과 안내 및 다음 이야기 링크를 제공한다.
- 이야기 공유 URL에 `s=friend|love|work`를 포함해 선택한 장면을 복원한다.
- 공유 링크의 일부 매개변수가 없을 때 브라우저에 저장된 오래된 다른 선택이 끼어드는 문제를 방지한다.
- 검증 스크립트에 12문항의 구조, 선택 축의 균형, 16개 결과 전체 및 잘못된 입력 테스트를 추가한다.

## 검증 구분
- 소스 구조와 데이터 테스트 코드를 추가했다. 저장소 실행 환경 및 실제 기기 브라우저에서 통과했는지는 별도로 확인해야 한다.
- 아직 미검증: 320/360/390/430px 휴대전화 시각 QA, iOS 공유·클립보드, Android 키보드·스크린리더, 캐릭터 원화의 투명도·통일성.
- ISTJ 고슴도치 원화는 여전히 검수용 시안이고, 승인 전 실제 카드에 연결하지 않는다.
- [v0.4.1 전체 소스·원화 백업 ZIP](https://drive.google.com/file/d/1TGFC6_75jtBeZNOEBgmx6gqGKzbuuESH/view?usp=drivesdk) 구글드라이브 보관 및 압축 검사 완료. SHA256: `9e66469987f328cf609c58e6dab8f45f4e58e1d92d4ba111f4383d187c898532`. 기존 v0.2·v0.4 ZIP도 보존.

## 수동 QA 절차
1. 320/360/390/430px 너비에서 사이트 상단과 16유형 카드/소다상점/탐험 선택지의 가로 넘침 여부를 확인한다.
2. 탐험을 열고 12문항을 모두 고른 뒤 추천 유형이 강조되는지, '이전 장면'과 '닫기'가 동작하는지 확인한다.
3. 키보드 Tab/Enter/Space로 탐험을 끝낸 뒤 결과에 초점이 이동하고, 스크린리더에 의미가 전달되는지 확인한다.
4. 유형·소다·친구·연인/동료 장면 선택 후 공유 URL을 새 브라우저 프로필에 열어 선택이 그대로 복원되는지 확인한다.
5. 기존 로컬 저장 선택이 있는 브라우저에서도 `?t=ISTJ&b=A`를 열었을 때 이전 친구·장면 선택이 섞이지 않는지 확인한다.
6. 시범 프로젝트 밖의 파일(특히 달빛운세, AI놀이터 루트, Actions)에 변경이 없는지 검토한다.
