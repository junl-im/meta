3초 영상 합성 실험실

실험 기능

원본 첫 3초에 참고 사진을 겹쳐서 기기 안에서 영상 파일로 저장해. 얼굴 영역 자동 검출은 선택 기능이며, 검출 모델 없이도 중앙 위치로 샘플을 만들 수 있어. AI 신원 교체나 자연스러운 얼굴 합성은 아직 아니야.

입력 점검과 사용 동의가 끝나면 실험할 수 있어. 출력 형식은 브라우저별 MP4 또는 WebM이며, 원본 오디오 보존은 지원 여부에 따라 달라져.

생성한 샘플 내려받기
LOCAL FIRST · 입력 파일 업로드 없음선택적 얼굴 위치 검출 · 얼굴 교체 AI 미구현

현재 버전 안내

v0.7.4은 설치 없는 웹판의 실험 단계야. 영상과 사진을 선택하고 로컬 미리보기·기기 지원 상태·입력 점검 파일을 확인할 수 있어.

3초 실험은 얼굴 사진 오버레이이며 실제 얼굴 교체 AI가 아니야. 얼굴 위치 검출을 선택하면 MediaPipe 파일과 모델을 CDN에서 다운로드하고 사용량 지표가 전송될 수 있어.

작업 화면에서 나갈까?

현재 선택한 로컬 파일은 이 화면에만 연결돼 있어. 나가면 다시 선택해야 해.
