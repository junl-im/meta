# 듣는 서재 음성 기술 조사와 구현 기준

조사일: 2026-10-30. 이 문서는 모델 제공자의 설명과 구현에서 확인한 사실을 구분한다.

## 후보

| 후보 | 장점 | 서재에 적용할 때의 제약 |
| --- | --- | --- |
| [Supertonic 3](https://huggingface.co/supertone-oss-archive/supertonic-3) | 한국어·ONNX·기기 내 합성, 남녀 기본 스타일, 표현 태그 | 처음에 큰 모델 다운로드와 기기 자원이 필요하다. 모델은 OpenRAIL-M이며 코드 MIT와 별도다. 기존 스타일을 쓰는 것은 새 성우 모델을 학습한 것이 아니다. |
| [Qwen3-TTS VoiceDesign](https://github.com/QwenLM/Qwen3-TTS) | 한국어와 자연어 지시에 의한 음색 설계 지원 | 큰 모델과 별도 실행 환경이 필요하다. 모바일 정적 페이지에서의 품질·속도와 모델별 조건은 별도 실험이 필요하다. |
| [VoxCPM2](https://github.com/xlf-x/VoxCPM2) | 한국어를 포함한 다국어와 자연어 음색 설계 지원 | 2B 모델로 기기·서버 자원과 한국어 장문 품질을 실제 확인해야 한다. |

Supertonic 원본은 한국어 문장을 다른 언어보다 짧게 나누는 기본값을 제시한다 ([설정](https://github.com/supertone-oss-archive/supertonic-py/blob/main/supertonic/config.py)). 공식 저장소 이슈에서는 표현 태그의 효과가 일정하지 않다고 설명하므로 ([관련 이슈](https://github.com/supertone-oss-archive/supertonic/issues/148)) 감정의 정확한 자동 해석으로 소개하지 않는다.

## 현재 구현

- 소리온 0.11.82의 Supertonic 래퍼와 helper를 서재용 worker로 재사용한다. 모델 원문은 Supertonic 저장소에서 내려받으며 소설 본문은 AI 서버로 전송하지 않는다.
- 온결(F2)과 해온(M1)은 기존 모델 스타일에 부여한 서재용 이름이다. 독자적으로 학습한 성우나 실제 인물의 복제 음성이 아니다.
- 자동 분위기는 문장 부호를 기반으로 속도를 조금 조정하는 단순 규칙이다. 소설 맥락이나 감정을 이해한다고 주장하지 않는다. 차분·생동감 설정은 사용자가 선택할 수 있다.
- 첫 사용의 대용량 다운로드, 발열·메모리·성능 및 긴 회차에서 생길 수 있는 지연을 사용자가 고려할 수 있게 안내한다.
- 실제 소리온 서버 방식과 브라우저 기본 음성은 별도의 선택지다.

## 남은 검증

- 실제 기기에서 긴 한국어 회차, 발음·대화·문장 누락, 두 목소리와 분위기별 청취 비교.
- 중단·재생·전경 복귀·장시간 연속 재생의 Android/iOS 실기기 확인.
- 모델 출처의 배포 정책·라이선스 유지 및 원문 권한 확인.
- 별도 성우 음색을 제작하려면 권리를 확보한 음성 데이터와 적절한 모델·학습·평가 환경이 추가로 필요하다.
