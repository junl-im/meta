# 곰같은여우 × 소리온 · 네이버 회차 연결 확장

Chrome/Whale PC용 Manifest V3 확장입니다. 네이버에 열어 둔 **AI놀이터 서재 등록 작품 29편의 회차 상세 페이지**에서 `#con_data` 본문을 읽어 현재 회차를 AI놀이터 `/NaverNovelShelf/site/listen.html`로 전달합니다.

## 설치

1. ZIP을 내려받아 압축을 풉니다.
2. Chrome `chrome://extensions` 또는 Whale `whale://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**하여 `manifest.json`이 들어 있는 폴더를 선택합니다.
4. 서재에서 네이버 작품을 열고 원하는 회차를 선택합니다.
5. 회차 오른쪽 아래 **소리온으로 듣기 ▶**를 누르거나 확장 아이콘을 누릅니다.
6. 새로 열린 서재 낭독 작업실에서 소리온/기기 음성을 선택합니다.

## 개인정보·제약

- 본문은 현재 열린 회차에서 사용자가 버튼을 눌렀을 때만 추출됩니다.
- 출처는 네이버 공식 웹소설의 `best` 및 `challenge` 회차이며 `novelId`는 AI놀이터 서재의 공개 작품 목록으로 제한됩니다.
- 네이버의 로그인·유료 회차 보호를 우회하지 않습니다.
- 본문은 확장 프로그램의 `chrome.storage.session`에 잠시 머무르고 서재로 전달한 직후 삭제됩니다. 만료 시간은 5분입니다.
- 서재 페이지에서 메모리로 처리하며 GitHub·정적 호스팅 서버로 올리지 않습니다. 실제 소리온 엔진으로 낭독하는 경우에만 연결된 음성 API에 보내집니다.
- 네이버가 HTML 구조를 변경하거나 본문을 이미지로 제공하면 자동 인식이 안 될 수 있습니다.
- 기본 Android/iOS 모바일 브라우저는 PC 확장 기능을 제공하지 않으므로 이 연결 방식은 PC 우선입니다.
- 소리온 성우 음색의 실제 낭독에는 별도 음성 서버와 승인된 목소리 파일이 필요합니다.
