# AI Cleaner 1.8.7

## 블로그 팩토리 — copy-first 리뉴얼

- 사용자 메뉴명 `AI 글쓰기 OS` → `블로그 팩토리`
- 기본 모드에 `오늘의 주제` 추가 및 기본값 변경
- `오늘의 주제`는 주제 10개 + TOP 3를 요청하는 복사용 프롬프트 생성
- 특정 AI 선택 UI 제거
- AI 새 탭 열기 제거
- 모바일 시스템 공유 전달 제거
- 비교용 원문 보내기 제거
- 생성된 프롬프트를 결과 영역에 항상 바로 표시
- 결과 행동을 `프롬프트 복사` + `.md 저장`으로 단순화
- `매일 자동 준비` 추가
  - 관심 분야를 로컬 저장
  - 새 날짜에 앱을 열면 그날용 프롬프트 자동 준비
  - 같은 날 재진입 시 오늘 프롬프트 복원
  - 브라우저가 닫혀 있을 때는 실행되지 않음
- 날짜 + 관심 분야 기반 `오늘의 탐색 각도` 회전 추가
- 브라우저 정적 페이지는 원격 AI를 호출하지 않으며 API 키를 요구하지 않음

## 자동화 경계

완전 무인 방식(앱을 열지 않아도 매일 실제 주제 결과 생성)은 정적 GitHub Pages만으로는 수행하지 않습니다. 서버 스케줄러, 서버 측 AI API 호출, 지속 저장소를 붙이는 별도 자동화 계층으로 분리합니다.

## 보호 범위

글 다듬기 및 이미지 검사 엔진, core/service/UI 모듈은 변경하지 않는 것을 기준으로 회귀 검증합니다.

## 안정화 점검

- `오늘의 주제`/`소재 20개`가 공통 BLOG 완성글 계약을 상속하지 않도록 모드별 출력 계약을 분리
- 오늘 프롬프트 캐시는 자동 준비 opt-in일 때만 저장
- `실제 경험/사실`, `중복 방지 메모`가 포함된 프롬프트는 일일 캐시에 저장하지 않음
- 주제 씨앗/독자/조사 설정/프로필 변경 시 signature로 같은 날의 오래된 캐시 무효화
- 업데이트 복원 상태가 초기 localStorage 로딩에 덮이지 않도록 pre-init 복원 순서 보강
