# AI Cleaner 1.9.0

날짜: 2026-08-18

## 교정 제안 일괄 반영
- 교정 제안 패널 상단에 `일괄 반영` 추가.
- `after` 치환값이 있는 deterministic 교정만 자동 적용한다. 반복 단어 등 판단이 필요한 `확인 항목`은 건드리지 않는다.
- `**결론적으로**`처럼 교정 범위가 겹치는 경우 한 번에 원본 인덱스를 덮어쓰지 않고, 비겹침 묶음 적용 -> 재분석을 반복해 안전하게 처리한다.
- 이미 개별 반영한 제안이 있으면 현재 결과를 기준으로 남은 제안만 일괄 처리한다.
- 일괄 작업 전체는 History 한 단계로 기록되어 `실행 취소` / `다시 실행` 한 번으로 되돌릴 수 있다.
- 패널 상태에 `바로 반영 N개 · 직접 확인 N개`를 표시한다.

## 검증
- 겹치는 Markdown + 전환어 + 연속 빈 줄을 일괄 적용하고 반복 단어 확인 항목이 남는 E2E 추가.
- 정적 검사에 bulk UI/안전 처리/history guard 추가.
- 글 다듬기 외 이미지 검사 / 블로그 팩토리 / Daily Engine 로직은 변경하지 않음.
