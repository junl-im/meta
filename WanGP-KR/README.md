# 곰같은여우의 AI 스튜디오 — WanGP 한국어 개인 작업실 (기획 단계)

> **현재 단계: 공식 소스 조사 완료 → 한국어 개인판 설계 시작.** 이 폴더는 원본 WanGP 엔진을 복제하거나 교체한 구현물이 아니라, **원본을 사용하기 위한 설계·연동 작업 공간**입니다. 실제 설치·실행·성능 검증은 아직 하지 않았습니다.

## 목표

- **무료 로컬 기본**: 원본 WanGP의 로컬 영상·이미지·음성·3D 생성은 GPT/API 없이 이용할 수 있게 유지. 사용 중인 모델·하드웨어 조건은 별도 확인.
- **GPT는 선택 사항**: 사용자가 원할 때만 Deepy Prime + Codex CLI 또는 ChatGPT MCP 연결을 켠다. Claude는 사용자 기본 화면에 노출하지 않되 원본 호환성은 삭제하지 않는다.
- **순수 한국어 사용자 경험**: 메뉴, 도움말, 상태, 작업 지시, 오류 메시지, 결과 관리 화면을 한국어로 제공. 원본 기능은 삭제하지 않음.
- **전 영역 보존**: 원본이 지원하는 영상, 이미지, 음성, 3D, Showrunner, Media Flow, LoRA, 후처리, 저VRAM 최적화, 갤러리, 큐, API/MCP를 유지.
- **개인 전용**: 기본값 로컬 실행, 명시적 동의 없이 공개 배포·외부 전송 금지. 단, Codex 같은 원격 LLM을 사용하면 일부 입력이 제공자에게 전송될 수 있음.
- **모바일 우선**: 좁은 화면에서 핵심 작업은 한 화면 흐름으로 제공하고 뒤로가기·작업 보존을 검증.
- **새 UI는 SVG 금지**: PNG/WebP와 CSS 중심. 기존 WanGP 엔진의 내부 자산은 임의 수정하지 않음.

## 실행 모드

1. **기본 무료 로컬** — 외부 LLM/API 인증 없이 원본의 로컬 미디어 생성·편집 기능 사용. 기본 선택.
2. **GPT 감독(선택)** — 사용자가 직접 활성화한 경우 Codex/ChatGPT 연결. 계정 조건·전송·사용량 안내.
3. **외부 GPU(선택)** — 로컬 하드웨어로 불가능한 작업만 사용자가 승인한 경우 유료 연산 검토.

자동 장편 제작 계획 등 **Showrunner의 감독 기능은 Deepy Prime이 필요**하다. 로컬 감독 LLM 사용은 하드웨어 자원 확인 후 제공하며, GPT는 필수가 아니다.

## Windows 전체 설치 (원본 WanGP 포함)

**사용자에게 권장하는 경로:** [Windows 전체 설치 안내](docs/FULL_INSTALL_WINDOWS_KO.md)를 보고 **[전체 설치 도우미 `.cmd` 파일 하나](scripts/install_studio_full_windows.cmd)를 다운로드한 뒤 더블클릭**합니다. 별도로 개발 브랜치 전체를 ZIP으로 받을 필요는 없습니다. 공식 WanGP Manager를 SHA-256 확인 후 실행하고, 원본 설치가 끝나면 한국어 플러그인을 추가합니다. 아직 실제 Windows에서 이 도우미를 끝까지 실행한 검증은 되지 않았습니다.

**모델 가중치는 필요할 때 받습니다.** 원본 WanGP 본체·라이브러리·한글 스튜디오는 설치하지만 모든 대형 모델 파일을 미리 내려받지는 않습니다.

## 원본 소스 가져오기

Git과 Python이 설치된 개인 PC에서 이 폴더를 내려받은 뒤:

```bash
python WanGP-KR/scripts/bring_upstream.py
```

원본 소스가 `WanGP-KR/runtime/WanGP/`에 내려받아지고 조사 기준 커밋으로 고정됩니다. 이미 폴더가 있다면 안전하게 중단합니다. **아직 이 스크립트를 실행한 상태는 아닙니다.** GPU 설치·모델 다운로드·렌더 테스트는 다음 단계입니다. `runtime/`은 Git 추적에서 제외됩니다.
