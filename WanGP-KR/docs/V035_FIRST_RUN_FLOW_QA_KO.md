# 곰같은여우의 AI 스튜디오 v0.35 — 첫 무료 제작 단계별 안내·복구 검수표

> 2026-11-06 · 개발용 코드/모의 UI 검증. 실제 Windows 16GB PC에서 WanGP를 실행하거나 GPU로 작품을 생성한 검증은 아닙니다.

## 변경 사항

1. **처음 실행 · 따라 하기**의 네 단계를 기존 드롭다운으로 직접 고를 수 있고 **다음 단계 설명 보기** 버튼으로도 ① → ② → ③ → ④ 설명을 진행할 수 있습니다. 버튼을 한 번 눌렀다는 사실로 이전 단계가 완료됐다고 기록하지 않습니다. 마지막 ④에서 누르면 그대로 유지합니다.
2. 각 단계 하단에 **막혔나요?** 안내를 짧게 제공합니다. ① 원본 실행/한글 탭 → ② 모델 목록·파일 준비/다운로드 → ③ 생성/메모리·큐 → ④ 갤러리·저장 파일 순서이며 기존 자세한 도움말은 보존합니다.
3. 제작 분야를 바꾸면 단계와 관련 설명·막힘 안내가 모두 첫 단계로 돌아갑니다. 모델 검색/준비 체크는 수동 조회·선택·확인 기능을 유지하되 기본 접힘으로 화면 밀도를 줄입니다.

## 사용자·실기기 확인 항목

- [ ] 360×740, 390×844, 430×932의 모바일 화면에서 단계 안내·버튼·막힘 안내가 오른쪽으로 넘치지 않는지 확인.
- [ ] ①에서 다음 단계 버튼을 누를 때 ② 모델 준비 설명이 나오고, 모델 검색은 자동 시작되지 않는지 확인.
- [ ] ②와 ③에서 다시 누르면 각각 ③·④로 이동하고, ④에서 눌러도 저장/생성 성공으로 기록되지 않는지 확인.
- [ ] 분야를 변경하면 ①로 되돌아가지만 다른 탭의 개인 프롬프트/작업 큐/원본 모델 설정은 그대로인지 확인.
- [ ] 모델 찾기와 수동 3개 체크가 필요한 경우 정상적으로 펼쳐지고, 선택은 사용자의 클릭으로만 바뀌는지 확인.
- [ ] 원본 WanGP Manager 설치 후 GPT 연결 없이 PC가 지원하는 작은 이미지 한 장을 실제 생성·갤러리 확인·파일 열기·시간/VRAM 기록. **미실시**.

## 안전 원칙

- 안내용 버튼과 문구는 고정 한국어 텍스트만 조합합니다. 사용자 오류 문구·프롬프트·경로를 출력하지 않고 외부 API·GPU·파일 시스템에 쓰지 않습니다.
- 원본 WanGP·모델·GPU/VRAM 정책·기존 플러그인·사용자 파일은 수정하지 않습니다. 신규 SVG 사용 없음, 기존 PNG/WebP 원화 유지, 무료 로컬 제작이 기본이며 GPT는 명시적 선택 사항입니다.
- Windows 전체 설치 및 읽기 전용 점검 도우미는 **14개 필수 파일을 고정 GitHub 소스 SHA와 개별 SHA-256으로 확인**해야 합니다. 기존 파일 덮어쓰기·자동 삭제 없음.
- 자동 회귀 시험은 코드와 모의 이벤트/정적 설치 계약을 확인합니다. 실제 Windows·Gradio 화면·저사양 GPU 무료 생성의 성공을 보증하지 않습니다.

이 검수표는 개발 PR #130에 포함하되 정식 배포 전 초안으로 유지합니다.
