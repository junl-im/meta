# v0.15 Windows 16GB 최초 실기기 검증 기록

> **상태: 아직 실기기 시험 전.** 개발 환경은 Linux이며 사용자의 Windows 16GB PC·GPU에 직접 접속하거나 이미지를 생성한 적이 없습니다. 이 문서는 결과를 수집할 양식입니다.

## 1. 실행 전

1. 원본·사용자 미디어를 백업하고, [공식 WanGP 릴리스](https://github.com/deepbeepmeep/WanGP/releases)를 확인합니다.
2. 아직 설치하지 않았다면 [Windows 전체 설치 도우미](../scripts/install_studio_full_windows.cmd)를 사용합니다. 공식 WanGP Manager의 실제 설치는 사용자가 진행합니다.
3. 설치 후 [읽기 전용 Windows 점검 도우미](../scripts/check_studio_windows.cmd)를 내려받아 실행합니다. 기본 경로를 못 찾으면 WanGP 설치 폴더를 입력합니다.
4. 화면의 **원본 구조 확인**, **필수 파일 14개 일치** 결과를 봅니다. 이 점검은 네트워크·설정 변경·파일 저장·생성 작업을 하지 않습니다. **현재 내려받는 도우미는 v0.16** 플러그인 소스 커밋 `6a47ee8` 기준입니다. 이 문서는 v0.15에서 처음 만든 실기기 기록 양식이며, 기존에 다른 버전을 설치했다면 정상 변경 파일도 불일치로 표시될 수 있습니다.
5. **검사 통과는 실행 성공 판정이 아닙니다.** 원본 WanGP Manager의 Start WanGP로 실행하고 한국어 플러그인을 켜서 UI와 모델 동작을 직접 확인해야 합니다.

## 3. 첫 무료 생성 순서

1. **원본 WanGP의 모델 목록에서** 실제 GPU·VRAM 요구 사항을 확인합니다. 지원 모델이 없다면 무리하게 모델 가중치를 받지 않습니다.
2. 조건이 맞는 작은 이미지 모델을 원본에서 선택합니다. 크기·해상도 등은 원본 지원 범위 내에서 수동 설정합니다.
3. GPT·유료 API 옵션은 켜지 않은 채 1장 생성하고, 결과가 파일로 저장되는지 확인합니다.
4. 모델명, 정밀도/프로필, 결과 성공 여부, 대략 소요 시간, 최대 VRAM 사용량을 개인적으로 기록합니다.
5. 이미지 생성이 정상 끝난 뒤에만 짧은 영상과 3D를 검토합니다. 지원되지 않는 경우 **지원 불가/미검증**으로 남깁니다.

모델이 실행된 것처럼 기록하거나 다른 PC의 벤치마크 값을 사용하지 않습니다.

## 4. 검증 판정

- **정적 코드 검사 통과**: Linux Python 유닛 및 스크립트 구조 점검만 완료한 상태.
- **구조 검사 통과**: Windows 점검 도우미에서 원본 파일과 플러그인 14개 해시가 맞는 상태. 아직 생성 성공 아님.
- **첫 생성 성공**: 실제 Windows 장비에서 직접 만든 출력 파일을 열어 결과와 소요 시간을 확인한 상태.
- **성능 검증 성공**: 사용자 장비에서 반복 생성하고 RAM·VRAM·속도·중단 여부를 기록한 뒤 판정. 한 번 성공으로 모든 모델을 지원한다고 주장하지 않음.
