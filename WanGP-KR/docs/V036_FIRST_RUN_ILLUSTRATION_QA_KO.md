# 곰같은여우의 AI 스튜디오 v0.36 — 첫 실행 일러스트·모바일 가독성 검수

> 2026-11-06 · 독립 여우·곰 WebP 아트와 화면 배치의 정적 검증용. Windows 16GB PC에서 실제 WanGP·Gradio 렌더나 GPU 무료 생성에 성공했다는 뜻이 아닙니다.

## 구현 범위

1. `first-run-helper-v036.webp`는 생성형 도구로 새로 제작한 투명 배경 여우·곰 안내 일러스트입니다. 640×640 WebP, 약 72KB, 기존 네 분야 카드·시그니처 배너·아이콘은 변경하지 않습니다.
2. **처음 실행 · 따라 하기** 시작 안내에만 전용 원화를 우측 하단에 장식으로 배치합니다. 한국어 제목·설명은 별도 HTML 텍스트로 유지해 확대·복사·접근성을 보존합니다. PNG/WebP 로컬 인라인 외부 CDN 없음, SVG 없음.
3. 740px 이하 및 420px 이하 좁은 화면에서는 그림 공간을 줄이고 제목·설명 글자 크기 및 오른쪽 여백을 보정합니다. 실제 기기·Gradio 화면에서 겹침 여부는 추가 확인이 필요합니다.
4. 그림 파일이 없거나 손상·과대하면 인라인 CSS를 생성하지 않고 기존 패널 배경 및 텍스트로 표시합니다. 원본 모델·GPU 정책·파일·큐·GPT 연동은 변경하지 않습니다.

## 직접 확인할 항목

- [ ] [독립 정적 배치 미리보기](V036_FIRST_RUN_VISUAL_PREVIEW.html)를 PC 폭 1280px, 740px 및 모바일 폭 360/390/430px에서 확인. 이는 실제 Gradio가 아닙니다.
- [ ] Windows에서 WanGP Manager를 설치하고 한글 탭의 새 여우·곰 원화가 잘리거나 왜곡되지 않는지 확인.
- [ ] 좁은 화면에서 인사말·단계 문장과 원화가 서로 가리지 않고 버튼과 텍스트가 화면 밖으로 나가지 않는지 확인.
- [ ] 이미 설치된 플러그인은 자동 덮어쓰지 않으므로 설치된 버전과 다운로드된 파일 15개의 검증 결과를 구분.
- [ ] 원본 Media Generator에서 작은 무료 이미지 1개 직접 생성, 실제 파일 열기·VRAM·시간 기록. 미실시.
- [ ] 장애 시 오류 원문·개인 경로·암호·토큰의 외부 노출 없는지 확인.

## 자동 검사와 한계

- Python 정적/모의 Gradio 검사는 이미지 파일 헤더, 크기, 로컬 배경 CSS, 파일 누락 대체 경로와 기존 이벤트를 확인합니다.
- Windows 설치 도우미는 공식 WanGP Manager를 사용하고 GitHub 소스 고정 및 파일별 SHA-256을 대조하며 기존 설치/사용자 파일 덮어쓰기나 자동 삭제를 하지 않습니다.
- CSS와 정적 미리보기만으로 실제 Windows 설치·Gradio 브라우저 렌더·모바일 터치·GPU 생성 성공을 증명할 수 없습니다. 이런 항목은 실기 확인 후 별도 기록합니다.
