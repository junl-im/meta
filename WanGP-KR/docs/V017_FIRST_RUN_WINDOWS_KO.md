# v0.17 Windows 16GB 첫 실행·오류별 복구 검수표

> 개발 중인 한글 스튜디오를 **실제 Windows PC에서 검증하기 위한 기록 양식**입니다. 이 문서를 만들었다고 Windows 설치·Gradio 실행·무료 이미지/영상 생성이 통과한 것은 아닙니다. 원본 WanGP와 개인 파일은 삭제하거나 자동 변경하지 않습니다.

## 검증 대상과 고정 원칙

- 한글 플러그인: **0.16.0-dev**, v0.16 소스 커밋 `6a47ee876b1d6134dc15fe1cf73e8b7ce3868e28`
- 설치 도우미: [`install_studio_full_windows.cmd`](../scripts/install_studio_full_windows.cmd)
- 설치 후 읽기 전용 검사: **v0.17** [`check_studio_windows.cmd`](../scripts/check_studio_windows.cmd)
- 기본 무료 로컬 제작, GPT/Deepy/Codex는 사용자가 선택할 때만 사용
- SVG 파일·태그·데이터 URI 추가 금지. 4종 WebP 및 PNG 배너·아이콘을 사용
- 원본 엔진·모델·VRAM 최적화·사용자 설정/파일은 수정하지 않음

## 1. 설치 후 읽기 전용 점검

1. WanGP Manager 또는 공식 원본을 설치한 위치를 기록합니다. 기존 작업과 모델 파일을 백업하고, 기존 한글 플러그인을 무조건 삭제하지 않습니다.
2. [점검 CMD](../scripts/check_studio_windows.cmd)를 내려받아 더블클릭합니다. 직접 폴더를 입력하는 경우 `wgp.py`와 `plugins`가 함께 있는 **원본 WanGP 폴더**를 지정합니다.
3. 화면의 세 단계가 모두 나타나는지 확인합니다: `1/3 원본 설치 폴더` → `2/3 필수 14개 파일 SHA-256` → `3/3 Windows·RAM·GPU`.
4. `검사 통과`가 나오더라도 이것은 **파일 무결성만 통과**한 것입니다. 설치 완료나 GPU 생성 완료로 표시하지 않습니다.
5. 결과가 불일치라면 아래 표의 해당 항목을 확인합니다. 이 CMD는 네트워크 요청·설정 변경·파일 다운로드·실제 생성·자동 복구를 하지 않습니다.

| 점검 결과 | 가능한 상황 | 안전한 다음 행동 |
|---|---|---|
| `원본 ... 확인하지 못했습니다` | 원본 미설치·설치 위치 오입력·불완전 설치 | 공식 WanGP Manager 설치 완료 여부와 `wgp.py`·`plugins` 위치 확인 |
| `한글 스튜디오 폴더를 확인하지 못했습니다` | 플러그인 설치 전·폴더가 다른 위치 | `plugins/wan2gp-gomfox-studio`를 확인. 기존 폴더는 삭제하지 않음 |
| `[누락] 파일명` | 14개 필수 파일 중 하나가 없음 | 원본 버전과 다운로드 완료 여부 확인. 자동 덮어쓰기 없이 원인을 먼저 기록 |
| `[불일치] 파일명` | 파일 변형·손상·다른 버전 | v0.16의 고정 소스와 설치 버전 확인. 기존 데이터 보호 후 원인 분석 |
| Windows/RAM/GPU 정보 없음 | WMI 접근 제한 등 | Windows 작업 관리자에서 직접 확인. 정보가 없다고 호환된다고 판단하지 않음 |
| 14개 파일 일치 | 필수 파일 무결성만 통과 | 2단계의 실제 프로그램 실행 검수를 별도 진행 |

## 2. 실제 화면·기본 동작 검수

이 단계는 **사용자 Windows 컴퓨터에서 직접 해야 하는 실기기 검사**입니다. 자동 테스트 통과와 별도로 기록합니다.

1. 공식 WanGP Manager의 `Start WanGP`로 원본 프로그램을 실행합니다.
2. 원본의 Apps & PlugIn Manager에서 **곰같은여우의 AI 스튜디오**를 활성화하고 필요한 경우 원본을 재시작합니다.
3. 한글 탭에서 PNG 배너·시그니처 아이콘과 영상·이미지·음성/음악·3D **WebP 원화 4개**가 선명하게 보이는지 확인합니다. 여우 캐릭터가 잘리거나 글자가 원화와 겹치지 않는지 살펴봅니다.
4. 분야별 카드를 하나씩 눌러 설명이 달라지는지 확인합니다. 무료 제작 버튼은 원본 화면으로 이동만 해야 합니다.
5. 초보자 도움말, GPU/RAM 읽기 전용 조회, 원본 모델 목록·작업 상태 조회를 확인합니다. 버튼 조회만으로 GPU 생성이나 GPT 연결이 시작되면 안 됩니다.
6. Windows 브라우저를 작은 너비로 줄여 카드 두 줄 간격·배너·탭 가로 탐색·글자 잘림을 확인합니다. 실제 휴대폰이 있다면 세로 화면과 낮은 높이 화면도 별도 확인합니다.

## 3. 실제 무료 생성 시험 — 조건이 맞는 PC에서만

- 모델 파일 다운로드는 원본 WanGP에서 **사용자가 직접 선택**합니다. 모델 크기·VRAM 요구량은 모델별로 다르므로 16GB RAM만으로 호환을 판정하지 않습니다.
- **이미지 1장:** 원본에서 지원되는 비교적 작은 모델을 선택해 기본 권장 해상도 또는 안정적인 저해상도로 시험합니다. 저장 파일이 실제 열리는지, 생성 시간과 GPU 메모리 사용량을 기록합니다.
- **짧은 영상:** 작은 이미지가 정상 처리되고 지원 모델·VRAM 조건이 맞을 때만 짧은 길이로 시험합니다. 여건이 부족하면 `미실행 — GPU/VRAM 조건 미충족`으로 기록합니다. 실패를 임의로 성공 처리하지 않습니다.
- GPT·유료 GPU·클라우드 API 로그인 없이 기본 로컬 모델 실행을 검증합니다. 사용자 승인을 받은 별도 선택 기능과 혼동하지 않습니다.
- 비정상 종료·메모리 부족·원본 오류는 실제 메시지와 발생 단계를 기록합니다. 사용자 사진·프롬프트·토큰·개인 경로가 포함된 로그는 공유 전에 가립니다.
