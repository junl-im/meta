# v0.21 — 저사양 PC 사양 안내 안전성·첫 무료 제작 검수

> 이 문서는 Windows 16GB PC에서 **직접 확인할 항목**을 정리한 개발용 검수표입니다. Linux의 자동 테스트 통과를 Windows GPU 생성 성공으로 간주하지 않습니다.

## 이번 변경

- 한글 스튜디오의 **내 PC RAM·GPU 확인** 버튼에서 메모리를 읽고 표시하는 기능을 개선했습니다. 클릭하지 않으면 진단하지 않습니다.
- CUDA를 통해 보고된 GPU별 이름·전용 메모리를 구분해 표시합니다. 여러 GPU 중 최대 값은 **시작 안내용**이며 원본 WanGP가 실제로 그 장치를 선택한다는 보장은 없습니다.
- `NaN`, 무한대, 음수, 0, 불리언, 터무니없이 큰 메모리 값을 **확인 실패**로 처리해 높은 VRAM이라고 오안내하지 않습니다.
- Windows의 GPU 이름만 확인된 경우 VRAM을 추측하지 않으며, **작업 관리자 → 성능 → GPU → 전용 GPU 메모리**를 직접 확인하라고 안내합니다.
- 안전한 첫 제작: 원본 모델의 **공식 요구 사양 확인 → 지원되는 경우 작은 이미지 한 장 → 결과 저장·소요 시간·메모리 기록**. 메모리 부족 시 GPU 점유 프로그램을 종료하고 원본의 더 작은 *공식 지원 모델*을 사용자가 직접 고릅니다.

## 읽기 전용·안전 경계

- **이 변경은 GPU를 벤치마크하거나 원본 설정·모델을 자동 선택/변경하지 않습니다.**
- CUDA의 장치 속성 조회도 실제 모델 구동·호환성 판단을 대신하지 않습니다.
- Windows `Win32_VideoController.AdapterRAM`은 용량이 잘리거나 오탐될 수 있어 진단에서 사용하지 않습니다.
- 설치와 실행 실패 시 기존 플러그인 폴더를 삭제하거나 검증을 우회하지 않습니다. v0.21 점검 도우미는 v0.19 이전의 정상 설치라도 버전 차이로 파일 불일치를 표시할 수 있습니다.
- GPT 로그인·유료 API·외부 GPU 연결은 무료 로컬 기본 흐름에 필요하지 않습니다. 단, 실제 모델에 맞는 GPU/메모리 및 모델 라이선스·다운로드 조건은 별도로 충족해야 합니다.

## 자동 검증과 미검증 영역

- Python 하드웨어 테스트는 잘못된 메모리 값, 다중 GPU, WMI 이름만 확인한 경우, 최초 실행 경고, 입력 불변성을 테스트합니다.
- 전체 Python 테스트는 설치 고정 해시, 기존 파일 보호, 원본 공식 Manager SHA-256 검증, 모의 UI 이벤트를 포함합니다.
- **실제 Windows 16GB 사양 인식, 공식 Manager, 브라우저 그리기, 로컬 GPU 이미지/영상 생성, Android 기기 성능은 아직 실행 검증 전**입니다.
