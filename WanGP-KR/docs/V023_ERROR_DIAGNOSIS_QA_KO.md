# v0.23 한국어 오류 문구 진단 · Windows 16GB 검수표

> 2026-11-05 · 개발판. **Linux 자동 검사와 Windows 실기 실행을 구분**합니다. 실제 Windows·원본 WanGP·GPU·모델 생성은 아직 실행 확인 전입니다.

## 바뀐 점

1. 원본 WanGP의 **처음 실행 · 따라 하기 → 문제가 생겼나요? 단계별 해결**에서 오류를 선택하거나 원본 오류 문장의 일부를 수동 입력합니다.
2. **한국어 진단 보기**를 누르면 로컬 Python 정규식으로 문구를 대조해 가능한 문제와 **안전한 다음 행동**을 안내합니다.
3. 분류 유형: GPU/RAM 메모리 부족, 디스크 용량 부족, GPU 드라이버/CUDA 불일치, 한글 플러그인 로딩, Python 모듈 누락, 모델 다운로드·네트워크, 실행 포트 충돌, 필수 파일 경로.
4. 오류를 인식하지 못하면 **알 수 없음**으로 표시합니다. 작업 상태나 하드웨어가 정상이라고 판정하지 않습니다.

## 개인정보·안전성

- **암호·API 키·토큰·개인 경로를 지운 뒤** 오류 부분만 입력합니다. 붙여넣은 내용은 로컬 WanGP UI의 Gradio 이벤트를 통해 플러그인 함수로 전달됩니다.
- 함수는 입력 문구의 마지막 최대 20,000문자만 분류하고, **원문을 결과 화면에 재출력하거나 별도 파일에 저장하지 않습니다.** 별도 HTTP/API 전송 코드가 없으며 GPT를 자동 활성화하지 않습니다.
- 로그를 자동으로 읽거나 원본 파일을 수정·복구·삭제하지 않습니다. Python 환경/드라이버/모델을 자동 설치·변경하지 않습니다.
- 진단 결과는 **문구 일치에 따른 추정**이며 원인 확정·지원 GPU 판정·생성 성공을 뜻하지 않습니다. 복합 오류일 때는 우선순위에 따라 한 개의 가능 원인부터 제시합니다.

## Windows 16GB 실기기 검수 — 미실시

| 순서 | 실제 수행할 작업 | 기록할 결과 |
| --- | --- | --- |
| 1 | 공식 WanGP Manager로 설치·Start WanGP 실행 | Windows 버전, 원본 실행 여부 |
| 2 | 별도 `check_studio_windows.cmd`로 14개 플러그인 SHA-256 확인 | 일치/불일치, 기준 소스 `071c662` |
| 3 | 한글 스튜디오 탭·영상/이미지/음성/3D 원화 4개 표시 | 깨짐·잘림·탭 로딩 오류 여부 |
| 4 | 오류 입력 없이 진단 버튼 → 안내 확인 | 오류 미입력 안내, 강제 실행 없음 |
| 5 | `RuntimeError: CUDA out of memory` 예시 입력 → 한국어 안내 확인 | 메모리 부족 유형, 복구 안내 문구 |
| 6 | `No space left on device`, `ModuleNotFoundError` 예시와 무관한 텍스트 입력 | 유형별 안내/알 수 없음, 원문 미노출 |
| 7 | 실제 발생한 원본 오류가 있으면 개인정보 제거 후 수동 진단 | 분류가 실제 원인과 일치하는지 별도 확인 |
| 8 | GPT를 연결하지 않은 상태로 원본 지원 모델의 작은 이미지 한 장 생성 | GPU 이름, 전용 VRAM, 소요 시간, 저장 성공 여부 |
| 9 | 좁은 브라우저/모바일 화면에서 입력·버튼·결과 가독성 확인 | 가로 넘침, 화면 잘림, 터치 오류 |

**중단 기준:** 기존 플러그인을 자동으로 덮어쓰려 하거나, 로그 원문/토큰을 결과에 출력하거나, 오류 진단 버튼만으로 모델 다운로드·유료 API·파일 삭제가 발생한다면 즉시 중단하고 수정합니다.
