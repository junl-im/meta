# 곰같은여우의 AI 스튜디오 v0.27 — Windows 실기기 진단·보고서 안내

> 2026-11-05 개발용. 신규 **Windows 실기기 증거 수집 도우미**의 사용 설명서입니다. 플러그인 본체는 `0.26.0-dev`, SHA-256 고정 설치 버전도 v0.26을 유지합니다. **실제 Windows 16GB PC와 GPU 생성 검증은 아직 실행하지 않았습니다.**

## 1. 어떤 파일을 사용하나요?

| 순서 | 파일 | 실제 수행하는 일 |
| --- | --- | --- |
| 1 | [`check_studio_windows.cmd`](../scripts/check_studio_windows.cmd) | 원본 구조와 플러그인 14개 파일 SHA-256 대조. 프로그램 실행 없음 |
| 2 | [`collect_studio_windows_qa.cmd`](../scripts/collect_studio_windows_qa.cmd) | Windows·RAM·GPU·드라이버 및 가능한 NVIDIA 전용 메모리 정보 읽기 |
| 3 | [`V020_WINDOWS_SMOKE_WORKBOOK.html`](V020_WINDOWS_SMOKE_WORKBOOK.html) | 사용자가 직접 확인한 원본 실행·무료 이미지 생성·파일 저장·경과 시간을 오프라인 기록 |

**단독 파일:** 새 진단 CMD는 별도의 `.ps1` 또는 Python/Git 설치 없이 Windows 기본 PowerShell을 이용합니다. 기존 원본 설치 위치를 못 찾으면 폴더를 직접 입력하거나 그냥 Enter로 건너뛸 수 있습니다.

## 2. 처음 실행하는 사용자 순서

1. 원본 WanGP를 아직 설치하지 않았다면 [공식 Manager를 사용하는 전체 설치 안내](FULL_INSTALL_WINDOWS_KO.md)를 먼저 확인하세요. 새 진단 도우미는 **설치를 대신하지 않습니다**.
2. GitHub에서 [실기기 진단 CMD](https://github.com/junl-im/meta/blob/feat/wangp-kr-planning-20261101/WanGP-KR/scripts/collect_studio_windows_qa.cmd)의 파일 내용을 확인한 후 **Download raw file**로 저장하고 더블클릭합니다. 출처를 모르는 파일에 대한 Windows 보안 경고를 무조건 무시하지 마세요.
3. 도우미에 표시되는 Windows 버전·총 RAM·사용 가능 RAM·GPU 이름·드라이버를 확인합니다. NVIDIA `nvidia-smi`가 설치되어 있고 동작한다면 **장치별 총 GPU 메모리(MiB)**도 볼 수 있습니다. 그 값은 실제 생성 시 남아 있는 VRAM이 아닙니다.
4. 마지막의 **TXT 저장 질문에서 N을 누르면 아무 보고서도 새로 만들지 않습니다.** Y를 누르면 CMD와 **같은 폴더**에 `gomfox-v027-windows-qa.txt` 파일을 생성하려 시도합니다. 같은 이름이 이미 있으면 덮어쓰지 않고 안내합니다. 폴더 쓰기가 제한되면 다른 폴더에서 다시 실행하세요.
5. 생성된 TXT는 내용을 직접 검토한 다음 필요한 부분만 공유하세요. 자동 업로드·원격 전송·개인 파일/프롬프트/비밀번호 수집은 하지 않습니다. 실제 디스크 경로도 출력 항목에서 제외합니다.
6. 별도의 무결성 도우미에서 14개 파일 일치를 확인한 후, **공식 WanGP Manager에서 직접 Start WanGP**를 눌러 정상 실행과 플러그인 탭을 확인합니다. 필요할 경우 첫 이미지 생성과 결과 파일을 직접 확인하고 오프라인 기록장에 기록합니다.

## 3. 보고서 해석 규칙

| 보고 내용 | 뜻 | 실제 성공으로 취급 가능한가? |
| --- | --- | --- |
| 원본 파일 구조 발견 | `wgp.py`와 `plugins` 폴더가 있음 | 아니요. 원본 실행은 별도 확인 |
| 한글 플러그인 폴더 발견 | 정해진 플러그인 폴더가 있음 | 아니요. 14개 SHA-256과 로딩은 별도 확인 |
| Windows·RAM·GPU·드라이버 표시 | 시스템 API가 읽은 환경 정보 | 아니요. 지원 모델 판정 불가 |
| NVIDIA GPU 총 VRAM | `nvidia-smi`가 실제 보고한 장치별 총 메모리 | 아니요. 여유 VRAM·지원 모델 요구량과 다름 |
| NVIDIA VRAM 조회 불가 | 해당 도구 없음/실행 실패 또는 미지원 | GPU 없음이라는 뜻이 아님 |
| 실제 앱/이미지 생성·파일 저장: 미검증 | 이 도우미가 아예 실행하지 않는 영역 | 실기기 수동 확인까지 보류 |

**모델 가중치/드라이버/필요 저장 공간/양자화·오프로딩/메모리 실제 사용량**은 원본 WanGP의 모델별 권장 사항과 실제 실행 결과를 확인해야 합니다. Windows의 `Win32_VideoController.AdapterRAM`은 저사양·공유 메모리 환경에서 부정확할 수 있어 보고서의 VRAM 합격 근거로 쓰지 않습니다.

## 5. 비파괴 안전 계약

- CMD는 `Get-CimInstance`, GPU 도구 조회, 존재 여부 확인과 선택형 TXT 저장만 사용합니다. 관리자 권한·외부 API·모델 다운로드·GPU 렌더링을 요청하지 않습니다.
- 파일 저장은 **사용자의 Y 선택 이후에만** 진행하며 기존 동명 보고서는 덮어쓰지 않습니다. 원본 WanGP 코드, 설치 폴더, 모델, 사용자 작업 파일을 수정·삭제하지 않습니다.
- 보고서에 추가 정보를 임의로 자동 수집하지 않습니다. 필요할 때만 사용자가 **오류 문구를 가린 후** 별도로 공유하세요.
- Linux 정적 테스트는 실제 Windows CMD/CIM/NVIDIA 도구 실행의 성공을 보증하지 않습니다. 최종 검수 결과는 반드시 Windows 실기기에서 작성해야 합니다.

## 6. 개발자 자동 검사

저장소 루트에서 다음 명령을 실행합니다.

```bash
python -m unittest discover -s WanGP-KR/tests -p 'test_*.py' -q
```

`test_windows_qa_collector.py`는 단독 CMD 경로, 보고서 저장 동의, 덮어쓰기 방지, 하드웨어 근거·미확인 상태 표시, 외부 호출·삭제 금지, 실패 경로를 정적으로 검사합니다. 실제 Windows 실행을 하지 않습니다.
