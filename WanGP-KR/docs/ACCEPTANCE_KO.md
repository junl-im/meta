# 한국어 개인판 합격 조건 및 테스트 계획

**목표:** 원본 기능·성능·품질 회귀를 조기에 잡는다. 현재 아래 결과는 모두 **미실행**이다. 검증 장치가 없는데 “통과”라고 표시하지 않는다.

## A. 설치 및 동일성

- [ ] 공식 WanGP 커밋 기록과 로컬 소스 상태 일치
- [ ] 버전·모델·LoRA·프리셋을 원본과 한국어판에서 동일하게 선택 가능
- [ ] 한국어 UI를 꺼도 원본이 완전히 정상 동작
- [ ] 기존 출력·워크스페이스·설정 백업·복구 가능
- [ ] 초기 실행에 비밀키를 코드나 GitHub에 저장하지 않음

## B. 기능 확인

- [ ] 텍스트→영상, 이미지→영상, 참조/제어 영상
- [ ] 이미지 생성·수정·마스크·참조
- [ ] 음성/음악/배경음/목소리 교체 (설치 모델 가용성에 따라)
- [ ] 3D 메시/텍스처/장면 복원 (설치 모델 가용성에 따라)
- [ ] Showrunner 브리프→샷 계획→재시도→조립, 사용자 승인
- [ ] Media Flow 복원·업스케일·배치
- [ ] 워크스페이스·갤러리·저장/내보내기·재시작
- [ ] 큐/취소/실패/재개 및 고급 파라미터
- [ ] GPT(Codex)/Claude/OpenCode 엔진 선택이 원본 지원 범위에서 동작
- [ ] MCP 웹 공용 큐, 중복 런타임 생성을 피하는 동작 확인
- [ ] 최신 원본에서 새 모델이 추가되면 한국어 화면에서 감지

## C. 성능·화질 비교 절차

각 테스트에 **GPU, 드라이버, OS, WanGP SHA, 모델 SHA/양자화, 프롬프트, 참조 파일, 시드, 해상도/FPS, 단계 수, 기타 설정**을 기록.

| 항목 | 비교 방법 | 합격 원칙 |
|---|---|---|
| 생성 결과 | 고정 입력+동일 모델/설정으로 원본 UI와 한글 UI 비교 | 한글 UI가 모델 입력을 변경하지 않음. 동일성은 연산 특성에 따라 허용 오차 기록 |
| 생성 소요 시간 | 동일 GPU, 동일 조건 3회 이상, 로딩 시간/추론 시간 구분 | 어댑터로 인한 유의미한 추가 지연 없음(측정 후 수치 목표 결정) |
| VRAM 피크 | 같은 성능 프로필·양자화에서 측정 | 원본과 유사, 회귀 시 원인 분석/출시 보류 |
| 샷 자동화 | GPT 감독/기본 감독을 같은 브리프로 비교 | 완성률·사용자 수정량·샷 일관성 측정; 우수성 선전 금지 |
| 복구 | 작업 중단·네트워크 끊김·앱 재시작 | 파일 손상 없이 작업 상태를 다시 조회·복구 가능 |

## D. UI·보안·접근성

- [ ] 주요 작업 경로 한글이며 의미 없는 영어 버튼 없음. 고급 모델 고유명칭은 원명 유지 가능.
- [ ] 모바일 한 화면 흐름, 브라우저/휴대폰 뒤로가기에서 진행 작업·초안 보호
- [ ] 팝업 우선 종료, 첫 화면의 나가기 확인, 취소·계속하기·복귀 검사
- [ ] 새 UI에 SVG 파일·태그·데이터 URI가 전혀 없음
- [ ] 외부 LLM으로 전송되는 이미지·영상 프레임·지시가 무엇인지 고지
- [ ] LAN/인터넷 공유 시 인증 설정. 기본 무인증 Web/MCP 포트를 공용 인터넷에 노출하지 않음
- [ ] 개인 출력물·음성·사진·토큰·설정이 공개 GitHub로 들어가지 않음
- [ ] 원본 WanGP 및 모델별 라이선스/표시 의무 확인

## E. 출시 판정

- **사용 가능:** 사용자 PC에서 최소 영상·이미지·자동 기획 1회 실측 + 기본 설정 저장/복구 + 원본 UI 복귀.
- **확장 가능:** 음성·3D·후처리 전 영역 실측 + 최신 모델 자동 노출 + 공용 큐 처리.
- **원본보다 낫다고 발표 가능:** 위 비교 로그와 사용자 생산성/작업 성공률 같은 재현 가능한 개선 증거가 확보된 이후.
