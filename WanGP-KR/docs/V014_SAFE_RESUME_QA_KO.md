# v0.14 설치 재시도·저사양 첫 제작 검수표

> 개발용 코드 검증 문서입니다. 실제 Windows 16GB PC에서 전체 설치 및 GPU 생성까지 통과했다는 뜻이 아닙니다.

## v0.13 대비 개선

- 기본 위치의 공식 WanGP에서 `wgp.py`와 `plugins` 폴더가 확인되면 **원본 설치 관리자 단계만 건너뛰는 선택**을 제공합니다. 사용자가 N을 선택하거나 설치 흔적이 불완전하면 공식 Manager를 내려받고 SHA-256을 확인한 뒤 실행합니다.
- 한글 플러그인 14개 파일은 여전히 고정된 GitHub 소스 커밋에서 내려받고 개별 SHA-256을 검사합니다. 이미 받은 검증 불가 임시 파일을 재사용하지 않습니다.
- 설치 오류가 났을 때 어떤 단계를 다시 시도할지 한글로 설명합니다. 기존 플러그인과 사용자 파일 삭제·강제 덮어쓰기 기능은 추가하지 않았습니다.
- RAM/GPU 보고서는 **지원 사양 확인 → 작은 이미지 → 가능한 경우에만 짧은 영상 → 파일·시간·메모리 확인**으로 이어지는 안내를 제공합니다. 모델 설정이나 GPU 사용량을 자동 변경하지 않습니다.

## 설치 도우미 오류별 대응

| 화면에 표시되는 상황 | 사용자 대응 | 자동 처리하지 않는 작업 |
| --- | --- | --- |
| 필수 파일 다운로드·SHA-256 실패 | 인터넷 및 GitHub 접근 확인 후 설치 도우미 처음부터 다시 실행 | 검증 실패 파일 실행·무결성 검사 생략 |
| 공식 WanGP Manager / `.sha256` 다운로드 실패 | 공식 릴리스 제공 상태를 확인하고 나중에 다시 시도 | 다른 비공식 실행 파일 대체 |
| 원본 설치 폴더 없음 | 공식 Manager에서 설치를 완료한 뒤 다시 실행 | 임의 폴더로 강제 플러그인 설치 |
| 이미 한글 플러그인 폴더 있음 | 기존 설치 상태·버전을 확인하고 그대로 유지 | 기존 폴더 삭제·덮어쓰기·자동 업데이트 |
| 임시 복사·폴더 이동 실패 | 원본 플러그인 상태를 확인하고 필요시 다시 실행 | 임시 폴더 자동 제거 또는 기존 파일 수정 |

## Windows 실기기 시험 시나리오 (미수행)

1. **완전 신규 설치:** 원본 WanGP가 없는 PC에서 공식 Manager가 다운로드·검증·실행되는지 확인.
2. **정상 원본만 설치된 PC:** 기본 설치 경로를 사용한 후 설치 도우미를 재실행. 선택 질문에서 Y를 누르면 Manager 창 없이 한글 플러그인 연결로 진행되는지 확인.
3. **다시 Manager 실행:** 같은 상황에서 N을 누르면 기존의 공식 다운로드·검증·실행 흐름을 유지하는지 확인.
4. **불완전 설치:** `wgp.py` 또는 `plugins` 폴더가 없는 **별도 테스트용 설치 폴더**에서 Manager 생략 선택지가 나오지 않는지 확인. 실제 사용자 설치 파일을 훼손하지 말 것.
5. **기존 한글 플러그인:** 이전 폴더가 이미 있으면 기존 데이터가 바뀌지 않고 안전 중단하는지 확인.
6. **다운로드·복사 오류:** 테스트 전용 복사본 및 네트워크 장애 재현 환경에서 종료 안내를 확인. 배포용 스크립트의 무결성 검사를 비활성화하지 말 것.
7. **저사양 첫 생성:** Windows 16GB 장비에서 GPU 모델·VRAM을 확인한 뒤 지원되는 원본 이미지 모델로 작은 이미지 1장 생성. 파일 저장 위치·시간·GPU 메모리·오류를 기록.
8. **확장 판단:** 첫 이미지 생성이 정상 완료된 경우에만 낮은 해상도의 짧은 영상 가능 여부를 조사. 실제 지원 여부·속도·화질은 실행해 측정.

## 아직 통과했다고 주장하지 않는 항목

- Windows CMD 실제 흐름, 공식 Manager 설치 마법사 및 `.ico` 변환
- WanGP Gradio GUI의 브라우저·모바일 표기와 원본 모델 세부 호환성
- 무료 로컬 이미지·영상·3D 렌더링 성공 및 RAM/VRAM·시간 측정

개인 파일이나 API 키가 포함된 설치 경로·로그는 공개 PR에 첨부하지 않습니다.
