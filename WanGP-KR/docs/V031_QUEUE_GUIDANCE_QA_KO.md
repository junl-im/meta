# 곰같은여우의 AI 스튜디오 v0.31 — 작업 큐 상태·다음 행동 QA

작성일: 2026-11-06

## 목적

원본 WanGP의 공용 작업 큐를 읽어 사용자가 **지금 무엇을 확인해야 하는지** 한국어로 안내한다. 기존 `format_queue_dashboard`의 두 출력 반환 형태는 유지하고, 새 화면에서는 `format_queue_dashboard_guided`가 요약·목록·안내의 세 항목을 전달한다.

## 화면 동작

1. **작업 현황 · 갤러리**에서 **현재 작업 상태 새로고침**을 누른다. 한 번의 `list_queue()` 호출로 요청 시점의 수·상태·모델 종류를 읽는다. 자동 반복 조회는 하지 않는다.
2. **실행 중**: 원본 생성 화면에서 상세 진행 상황을 확인한다. 개별 퍼센트나 완료 시간 추정은 표시하지 않는다.
3. **대기 중**: 중복 제출 없이 기다렸다가 다시 조회한다.
4. **취소 처리 중**: 원본에서 취소 완료를 확인하기 전까지 같은 작업을 중복 제출하지 않는다.
5. **대기·실행 모두 없음**: 원본 갤러리에서 결과가 저장됐는지 보고, 원본 오류 화면에서 실패 여부를 확인한다. 큐 비움은 성공을 의미하지 않는다.
6. **조회 실패·API 미제공·응답 불완전**: 확실하지 않은 수치를 `?`로 표시하거나 오류 안내를 보이며, 원본 화면에서 직접 상태를 확인한다.

프롬프트는 **기본 숨김**, 사용자가 체크박스를 켠 경우에만 별도로 표시한다. 내부 예외 원문·로컬 경로·비정상 객체는 표시하지 않는다.

## 기술 근거·보존 범위

- WanGP 공식 API의 `list_queue()`는 `total_count`, `running_count`, `queued_count`, `tasks`를 제공한다. 개별 작업은 `queued`, `running`, `cancelling` 상태일 수 있다. 완료 항목과 개별 진행률(%)은 이 응답에서 제공되지 않는다.
- 이 기능은 읽기 전용이다. 큐 제출·취소, 모델 다운로드·선택, GPU 생성, 원본 설정 변경, 기존 사용자 파일 삭제·덮어쓰기를 수행하지 않는다.
- 무료 로컬 생성 기본, GPT 감독 명시 동의, PNG/WebP 원화, 신규 SVG 금지를 유지한다.
