# v0.8 — 모델 상세와 작업 현황 (2026-11-01)

이 문서는 실제 Windows·GPU 시험 전의 개발판 사용 안내입니다.

## 새로 추가된 화면

### 모델 찾아보기 → 모델 정보 확인
1. **원본 모델 목록 조회**로 원본 WanGP 모델을 읽습니다.
2. 검색 결과의 대괄호 안에 표시되는 **모델 ID**를 복사해 입력합니다.
3. **모델 정보 확인**을 누르면 원본 API의 기능·입력 종류·모델 파일 준비 상태를 조회합니다.

- 조회 자체는 모델 파일을 다운로드하지 않고 GPU를 실행하지 않습니다.
- 파일이 설치되어 있다고 해서 VRAM이 충분하다는 뜻은 아닙니다.
- 새로운 모델 목록은 원본 WanGP 메타데이터를 기준으로 합니다.

### 작업 현황 · 갤러리
1. **현재 작업 상태 새로고침**을 눌러 WanGP 공용 큐의 실행 중·대기 중 수를 확인합니다.
2. 작업 내용은 기본 숨김입니다. 필요할 때 **작업 내용도 표시하기**를 체크합니다.
3. 결과물은 **원본 WanGP 제작·갤러리 화면으로 이동** 버튼으로 확인합니다.

- 이 화면은 조회 전용이며 작업 취소·삭제·재실행을 하지 않습니다.
- WanGP의 list_queue API는 대기·실행 중·취소 처리 중 상태를 제공하지만 개별 진행률 백분율은 제공하지 않습니다.
- 현재 스튜디오에 독립 썸네일 갤러리를 구현했다고 주장하지 않습니다. 원본 갤러리를 이용합니다.
- 원본 WanGP가 해당 API를 제공하지 않는 이전 버전이면 안전한 안내를 보여 줍니다.

## 유지하는 원칙

- **무료 로컬 생성** 기본, GPT/Deepy 선택 OFF
- **원본 엔진·가중치·GPU 정책 미변경**
- 외부 API 요청·파일 변경 없이 모델/작업 정보를 읽기만 함
- 한글 플러그인 새 자산에 SVG 없음
- **정식 출시 전 Windows 16GB + 실제 GPU로 설치/생성/큐/갤러리 검증 필요**
