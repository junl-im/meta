# v0.16 시작 화면 디자인 정밀 검토

> 원본 WanGP 엔진과 모델 설정은 수정하지 않은 **플러그인 화면 코드·오프라인 미리보기 검토 기록**입니다. Windows/Gradio 실제 브라우저 렌더링·모바일 실기 검증은 아직 하지 않았습니다.

## 직접 확인한 원화와 배치 문제

네 개의 WebP는 각각 약 2:1 가로 구도의 독자 원화이며, 캐릭터가 화면 오른쪽, 제목용 여백이 왼쪽에 있습니다. 기존 UI의 가로로 긴 버튼은 원화의 위·아래를 과하게 잘라 여우 얼굴·몸통이 일부 잘릴 가능성이 있었습니다. 두 번째 카드 줄은 첫 번째 줄에만 적용된 간격 설정에서 빠져 있었습니다.

| 발견 내용 | v0.16 수정 | 확인해야 할 실제 화면 |
| --- | --- | --- |
| 카드의 짧은 높이·중앙 크롭 | 기본 높이 154→184px, 배경을 오른쪽·세로 67%에 정렬 | 네 분야 여우 캐릭터 잘림 여부 |
| 첫 줄과 둘째 줄 간격 차이 | 두 `gr.Row`에 구분 ID 및 공통 간격 규칙 적용 | 2열 카드 너비·간격·세로 정렬 |
| 그림 위 텍스트 가독성 | 왼쪽에만 어두운 점진 오버레이, 시스템 한글 폰트·자간 정리 | 글씨가 원화와 충돌하는지 |
| 배너/아이콘 이미지 높이 불일치 | Gradio 컴포넌트 높이와 CSS 높이를 맞추고 모바일에서 외부 영역까지 축소 | 모바일에 빈 이미지 영역이 남는지 |
| 중첩된 테두리·강한 그림자 | 소개·워크숍·상태 패널 테두리 제거, 카드 그림자와 호버 효과 완화 | 버튼과 패널 디자인 통일성 |
| 첫 화면의 긴 기본 도움말 | 카드 선택 전에는 한 줄 안내만 표시, 선택 후 기존 도움말 출력 | 모바일에서 첫 화면이 과도하게 늘어나는지 |
| 키보드·터치 조작 | 포커스 강조 유지, 호버 연출은 마우스 환경에 한정 | 터치 시 버튼 고정 호버·초점 표시 문제 |

## 유지한 설계 원칙

- 각 분야의 기존 고유 WebP 원화 **4개를 모두 재사용**하고 PNG 배너·시그니처 아이콘도 유지했습니다. SVG·원격 CDN·외부 폰트를 추가하지 않았습니다.
- 카드 클릭 시 분야별 원본 도움말이 바뀌는 이벤트, **무료 제작 화면 이동**, 읽기 전용 진단, 모델 목록·큐·갤러리, 선택형 GPT 동의는 그대로입니다.
- CSS에서 색상·배경과 크기를 조정했을 뿐 원본 WanGP의 GPU/VRAM 정책, 이미지·영상 모델, 프롬프트·결과 파일을 변경하지 않았습니다.
- [v0.16 오프라인 디자인 미리보기](V016_VISUAL_PREVIEW.html)는 레이아웃 비교용입니다. 실제 Gradio UI와 픽셀 단위로 일치한다는 보장은 없습니다.

## 후속 실기 검수 (미수행)

1. Windows 브라우저 1920×1080 및 1366×768에서 첫 화면 네 카드와 제목이 겹치지 않는지 확인.
2. Android 모바일 360×740, 390×844, 가로 화면에서 배너 높이·캐릭터 크롭·카드 2열 간격을 확인.
3. 브라우저 확대 125% 및 글자 크기 확대에서 문장 잘림·스크롤을 확인.
4. Windows 다크/라이트 테마와 Gradio 테마에서 탭 선택 색·텍스트 대비를 확인.
5. 네 카드를 하나씩 눌러 안내 출력과 원본 무료 생성 화면 이동이 원래대로 동작하는지 확인.
6. 첫 화면을 여러 번 전환해도 원화 이미지 로딩·메모리 누수가 없는지 확인.

실제 검수 후 문제가 발견되면 화면 캡처와 브라우저·해상도만 기록하고, 개인 생성 파일이나 인증정보는 공개 저장소에 올리지 않습니다.
