# 곰같은여우의 AI 스튜디오 v0.33 — 첫 무료 생성 준비 단계 수동 점검

> 2026-11-06 · 개발 검수표. Windows 16GB RAM PC·실제 GPU 생성·원본 WanGP 실행 및 저장 파일 검증은 아직 수행하지 않았습니다.

## 목적

첫 방문자가 원본 WanGP의 무료 로컬 제작 단계에서 무엇을 확인했는지 잊지 않도록 돕는 **선택형 체크리스트**입니다. 플러그인은 원본 설정·모델 파일·출력물을 수정하거나 작업을 제출하지 않습니다. GPT/Deepy는 기본 비활성·선택 사항입니다.

## 사용자 시나리오

1. **처음 실행 · 따라 하기** → 제작 분야 선택 → **첫 무료 생성 · 지금 어디까지 확인했나요?** 펼치기.
2. 원본 `Media Generator`를 직접 열었으면 ① 원본 화면을 체크합니다.
3. 원본 화면에서 모델을 직접 고르고 모델 파일 상태를 직접 확인했으면 ② 모델 파일 확인을 체크합니다. **첫 작품 모델 찾기** 탭 조회만으로 ②를 자동 체크하지 않습니다.
4. 프롬프트·해당 모델의 필요한 입력과 낮은 해상도·짧은 길이 등의 시작 설정을 원본에서 직접 확인했다면 ③ 입력 확인을 체크합니다.
5. 체크를 바꾸거나 **아직 필요한 단계 확인**을 누르면 확인한 개수와 누락 단계 안내가 나타납니다. 3/3을 체크해도 **실행 준비가 보장되는 것은 아닙니다.**
6. **원본 무료 제작 화면 열기** → 원본에서 직접 생성 → 원본 갤러리·오류 표시·로컬 저장 파일 확인. 문제가 있다면 **문제가 생겼나요? 단계별 해결**과 한국어 진단을 사용합니다.

## 코드·UI 검수

| 검수 항목 | 기대 결과 |
| --- | --- |
| 첫 화면 | 수동 체크 3개 모두 해제, 0/3 다음 행동 표시 |
| 원본만 확인 | 1/3, 모델 파일과 입력 확인 안내 표시 |
| 임의 순서 확인 | 빠진 항목만 표시, 3/3 오판 금지 |
| 전부 체크 | 3/3이지만 GPU 실행·모델 호환성·파일 저장 **미검증** 표시 |
| 제작 분야 변경 | 세 체크 모두 해제, 0/3 결과로 초기화 |
| 입력 오염 | 임의 문자열·HTML은 그대로 재표시하지 않음, 체크값은 정확한 `True`만 인정 |
| 모델/API 부작용 | 체크·상태 안내 버튼은 원본 세션 API를 호출하지 않음 |
| 모바일 (수동) | 360×740 / 390×844 / 430×932에서 체크 라벨·버튼·안내 줄바꿈, 화면 이탈 없는지 확인 |
| Windows 16GB (수동) | 파일 무결성 검사 → 원본 실행 → 이미지 한 장 생성 → 실제 파일 열기 검증 |

## 미완료 항목

- 실제 Windows·전용 VRAM 부족 GPU 환경에서 모델별 다운로드·생성 성공률 및 생성 시간 계측.
- 브라우저/모바일 실기에서 응답형 UI 시각 점검. 모의 Gradio 이벤트 연결 검증만 자동화.
- 원본 WanGP 갤러리·파일을 플러그인이 자동 판정하지 않음(의도된 제한).

`v0.33.0-dev`는 정식 출시 버전이 아닙니다. 원본 기능과 기존 프로젝트 데이터를 그대로 보존하고, Draft PR 상태에서 검토합니다.
