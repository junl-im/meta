# 곰같은여우의 AI 스튜디오 — v0.20 Windows 실제 무료 생성 기록 준비

> 기준일: 2026-11-05. 이번 단계는 **실제 Windows 테스트에 쓸 오프라인 기록장과 절차 제작**입니다. 사용자 Windows 16GB PC, 공식 WanGP Manager, Gradio 브라우저 또는 GPU 생성 작업을 이 개발 환경에서 실행해 검증했다는 뜻이 아닙니다.

## 검수 도구

1. 기존 [Windows 설치 후 읽기 전용 점검 CMD](../scripts/check_studio_windows.cmd)로 원본 `wgp.py`·`plugins` 구조, 한글 플러그인 **14개 파일 SHA-256**, Windows/RAM/GPU 이름을 확인합니다. 이 CMD는 v0.19 플러그인 파일을 기준으로 하며 자동 수정·설치·GPU 생성이 없습니다.
2. 새 [v0.20 오프라인 실기기 기록장](V020_WINDOWS_SMOKE_WORKBOOK.html)을 다운로드한 후 **같은 PC의 웹 브라우저에서 직접 열어** 사용합니다. HTML 한 파일로 동작하므로 네트워크나 별도 패키지 설치가 필요 없습니다.
3. 네 단계를 따라 사용자에게 보이는 실제 결과만 체크합니다. **PC 정보 → 원본·한국어 탭 실행 → GPT 없는 무료 이미지 1장 생성 → 결과 정리** 순서입니다.
4. 이미지 생성 버튼을 누를 때 기록장의 **측정 시작**, 저장이 끝났을 때 **측정 종료**를 누릅니다. 타이머는 기록장 내부 시간만 세며 WanGP 모델 생성이나 GPU를 직접 조작하지 않습니다.
5. 결과의 **TXT 저장** 버튼으로 PC 다운로드 폴더에 내려받고, 파일이 실제로 존재하는지 확인합니다. 결과에는 개인 프롬프트·경로·비밀번호·API 키를 적지 않습니다. 업로드·자동 전송 기능은 없습니다.

## 단계별 판정

| 항목 | 사용자 확인 기준 | 아직 확인하지 않았다면 |
|---|---|---|
| PC·무결성 | OS·RAM·GPU를 직접 입력하고 CMD의 14개 파일 SHA 결과가 모두 일치 | 미검증. 기존 버전이면 무결성 불일치가 손상을 뜻하지 않을 수 있음 |
| 실제 실행 | 공식 WanGP 화면, 한국어 탭, 영상·이미지·음악·3D 원화를 직접 확인 | 미검증 |
| 첫 무료 생성 | 모델명 기록, 원본에서 이미지 생성, 시간 측정 종료, 생성 성공·파일 저장 확인 | 미검증 또는 지원 모델 없음으로 기록 |
| 검수 산출 | TXT가 로컬 다운로드 폴더에 저장되었는지 실제 확인 | 기록장에 다운로드 요청만 보낸 상태는 저장 성공이 아님 |

**중요:** 기록장의 “사용자 체크 기준 완료”는 사용자가 항목을 모두 확인했다는 뜻입니다. 실제 GPU 및 Windows 버전의 자동 성능 계측·호환성 인증이 아닙니다. 결과 파일과 실제 화면·모델·오류 로그의 대조가 필요합니다.

## 실기기에서 반드시 추가 확인할 항목

- [ ] Windows 10/11, 시스템 RAM 16GB, 실제 GPU 모델과 **전용 VRAM** (작업 관리자 성능 탭 값)
- [ ] WanGP Manager 설치 경로와 원본 플러그인 화면 정상 표시
- [ ] 1366×768 PC, 360×800·390×844 모바일의 원화 잘림·제목·스크롤·버튼
- [ ] 사용 가능한 이미지 모델의 요구 VRAM·디스크 용량을 원본 모델 안내에서 확인
- [ ] 실제 생성된 이미지 파일 1개, 저장 폴더, 생성 소요 시간, VRAM 최고치
- [ ] 영상/3D/음악은 GPU·모델 호환성이 확인된 뒤 별도 단계로 평가
- [ ] GPT/Codex/유료 API를 연결하지 않은 **무료 로컬 생성** 확인
- [ ] 오류가 나면 개인 파일 삭제·GPU 옵션 강제 변경 없이 재현 순서만 기록

## 실기 검증 상태

- Linux 기반 오프라인 HTML 구조·자바스크립트 문법·개인정보/외부 연결 금지 계약 검사: **기존 검사 포함 총 76개 통과**. 브라우저 화면은 아직 픽셀 검증 전입니다.
- 실제 Windows에서 실행, CPU/GPU 메모리, 무료 이미지 생성 및 저장, Android 실기기: **모두 미검증**.
- GitHub PR #130은 실제 시험 결과 확인 전까지 **Draft**, 정식 배포·병합하지 않음.

## 사용자에게 보여 줄 순서

1. [Windows 전체 설치 안내](FULL_INSTALL_WINDOWS_KO.md)를 따라 공식 원본 WanGP까지 설치합니다. 아직 설치하지 않았다면 무리하게 생성 검수를 시작하지 않습니다.
2. 설치 후 읽기 전용 CMD로 설치 상태를 확인합니다.
3. 오프라인 HTML 기록장을 열고 직접 사용한 결과를 입력합니다.
4. 결과 TXT와 필요한 오류 화면만 사용자 판단으로 공유합니다. 비밀키·개인 작품 데이터는 공유하지 않습니다.
