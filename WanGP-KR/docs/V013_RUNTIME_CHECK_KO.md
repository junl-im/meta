# v0.13 시작 점검 및 원본 호환성 확인

> 이 문서는 **읽기 전용 진단 기능의 코드 검증 기록**이다. 실제 Windows 설치·Gradio 브라우저·GPU 생성은 별도 실기기 검증이 필요하다.

## 무엇이 달라졌나

- 첫 탭 **무료 제작 · 시작** 아래의 접힌 **시작 전 확인**을 열면 두 버튼이 보인다.
  - **스튜디오 준비 상태 확인**: 4개 WebP 원화의 파일 형식, 배너·아이콘·플러그인 정보 파일, 원본 모델 메타데이터 API와 큐 API의 연결 가능 여부를 표시한다.
  - **내 PC RAM·GPU 확인**: 이전 읽기 전용 PC 진단을 첫 탭에서도 이용한다. OS·GPU/VRAM을 보고 가벼운 작업부터 시작하도록 안내한다.
- 원화 파일이 없거나 WebP 형식이 잘못된 경우, UI 생성 자체가 중단되지 않도록 기존 CSS 색상 버튼을 사용한다.
- 모델 메타데이터를 읽지 못하면 **예외의 종류만** 표시하고 PC 경로·토큰 같은 예외 상세 내용은 노출하지 않는다.
- 실행 중인 큐는 **API 존재 여부만 확인**하며, 진단 과정에서 작업 큐를 호출하거나 모델을 생성하지 않는다.
- 원본 WanGP 생성 모델·드라이버·설정·저VRAM 정책은 수정하지 않는다.

## Windows 16GB 실기기에서 확인할 항목

1. 공식 WanGP Manager로 설치·실행하고 한국어 플러그인을 켠다.
2. 네 원화 버튼의 배경·텍스트·클릭 동작을 확인한다.
3. **시작 전 확인**을 펼쳐 **준비 상태 확인**을 누른다. WebP `4/4`, 모델 메타데이터와 큐 API 항목이 나타나는지 확인한다.
4. **내 PC RAM·GPU 확인**을 눌러 OS·RAM·전용 VRAM 보고가 정확한지 작업 관리자와 비교한다. 이 결과로 모델 호환성을 단정하지 않는다.
5. 원본 **Media Generator**에서 장비가 지원하는 가장 작은 이미지 모델로 1장 생성해 결과 파일과 시간을 확인한다.
6. 원본 **모델 목록·큐·갤러리**, 그리고 GPT 기본 비활성 여부를 확인한다.
7. 파일 하나가 없거나 손상된 **복사본 개발 환경에서만** 오류를 재현해 색상 버튼으로 대체되는지 확인한다. 실제 설치본을 망가뜨리지 않는다.
