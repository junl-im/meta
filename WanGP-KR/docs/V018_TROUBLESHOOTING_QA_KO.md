# v0.18 초보자 상황별 문제 해결·안전 설치 검수표

> 개발 상태: `0.18.0-dev`. 2026-11-04. 원본 WanGP와 Windows 16GB·저사양 GPU의 실제 실행, 무료 생성 속도, 결과 저장은 **미검증**입니다. 아래 자동화 검사는 Linux의 소스·모의 UI 검사이며 실기기 테스트가 아닙니다.

## 새로 달라진 점

- **처음 실행 · 따라 하기** 탭의 기존 3단계 아래에 접혀 있는 **문제가 생겼나요? 단계별 해결** 안내를 추가했습니다. 첫 화면과 기존 8개 상단 탭 수는 유지합니다.
- 문제를 선택하면 다음 6가지 고정 한국어 안내가 즉시 바뀝니다.
  1. 원본 WanGP가 열리지 않아요
  2. 한글 스튜디오 탭이 안 보여요
  3. 그림 카드가 비거나 잘려 보여요
  4. 모델 다운로드·생성이 멈춘 것 같아요
  5. 만든 파일을 찾지 못하겠어요
  6. GPT 없이 무료로 만들고 싶어요
- 이 안내는 읽기 전용입니다. 모델 다운로드, 원본 설정 변경, 기존 폴더 삭제, GPT/API 요청, GPU 작업을 직접 실행하지 않습니다.
- 플러그인 버전·설치 도우미·Windows 점검 도우미를 동일한 `v0.18` 소스 커밋과 필수 14개 파일의 SHA-256으로 동기화했습니다. **이미 설치된 이전 버전을 자동 덮어쓰거나 삭제하지 않습니다.**

## 오류가 생겼을 때

1. 우선 한글 탭 → **처음 실행 · 따라 하기** → **문제가 생겼나요? 단계별 해결**을 확인합니다.
2. `scripts/check_studio_windows.cmd`를 별도로 실행하면 Windows 버전·RAM·GPU 이름 및 설치 파일 14개의 무결성을 **읽기 전용**으로 대조합니다. 검사 통과가 실제 GPU 생성 성공을 의미하지 않습니다.
3. 확인에 실패한 파일명, 원본 마지막 오류 문장, GPU 모델 및 사용 모델을 기록합니다. **암호, API 키, 개인 사진은 공개 저장소에 올리지 않습니다.**
4. 이전 버전의 플러그인 파일이 점검 도우미에서 불일치로 나오는 건 정상일 수 있습니다. **임의 삭제·덮어쓰기 대신 버전을 먼저 대조**하세요.

## 이번 패치의 검증 경계

- Python 도움말 안전 대체, 6가지 안내 내용, Gradio 모의 UI의 선택 변경 이벤트, 원본 비침습성, SVG 없음, Windows CMD의 SHA-256 일관성을 검사합니다.
- Windows `.cmd` 실제 실행, 원본 WanGP 진입, WebP 렌더링, Android 브라우저, VRAM 적합성, 모델 다운로드·생성 시간은 **별도 실기기 검수 필요**.
- 무료 로컬 기본·GPT 선택·원본 WanGP 보존 정책은 변경하지 않습니다.
