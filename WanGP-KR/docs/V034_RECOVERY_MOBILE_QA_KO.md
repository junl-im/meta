# 곰같은여우의 AI 스튜디오 v0.34 — 오류별 복구 도움말·모바일 정렬 검수표

> 2026-11-06 · 개발판. Windows 16GB RAM/저사양 GPU/Android 실기기와 실제 생성 테스트는 여전히 미검증.

## 이번 개선

`처음 실행 · 따라 하기` → `문제가 생겼나요? 단계별 해결`에서 사용자가 붙여넣은 **개인정보를 가린 오류 메시지**를 기존 한글 유형 분류기로 확인합니다. 인식 가능한 유형이면 대응하는 **기존 상황별 해결 도움말 주제**로 수동 선택값과 본문을 함께 전환합니다. 인식하지 못하면 사용자가 고른 도움말을 유지합니다.

| 입력 오류 유형 (패턴만 비교) | 추천 도움말 |
| --- | --- |
| 저장 공간 부족, CUDA/RAM 부족, 드라이버 문제 | 모델 다운로드·생성이 멈춘 것 같아요 |
| 모델 다운로드·네트워크 오류 | 모델 다운로드·생성이 멈춘 것 같아요 |
| 한글 플러그인 불러오기 오류 | 한글 스튜디오 탭이 안 보여요 |
| Python 모듈, 포트 충돌, 파일 경로 누락 | 원본 WanGP가 열리지 않아요 |
| 모르는 오류·빈 입력 | 자동 추천하지 않고 사용자가 선택한 항목 유지 |

## 동작 검수

1. **개인정보를 제거한 오류만 붙여넣기**: 토큰·이름·로컬 파일 경로·사진·키 입력 금지 안내 확인.
2. **한국어 진단 보기**: 오류 분류 결과와 대응하는 기존 도움말이 동시에 갱신되는지 확인.
3. **미인식 메시지**: 원인 확정처럼 보이지 않고, 선택한 수동 도움말이 유지되는지 확인.
4. **입력 지우기**: 오류 입력·진단 결과·추천 도움말을 기본값으로 초기화하는지 확인.
5. **모바일 360×740, 390×844, 430×932**: 오류 입력, 도움말 제목/목록, 버튼 2개, 긴 한국어 문장이 화면 밖으로 나가지 않는지 실기 확인 필요.
6. **원본/파일 안전**: 이 버튼들은 원본 API·GPU·파일·모델·GPT를 호출하거나 수정하지 않음. 기존 작업/이미지는 그대로 보존.

- Python 단위 테스트에서 오류 패턴→고정 주제 매핑, 미인식 입력/로그 민감정보 비노출, 모의 Gradio 이벤트 연결, 모바일 CSS 존재 여부를 검사.
- Windows CMD 고정 소스·14개 SHA-256 대조 및 기존 플러그인 덮어쓰기 금지 회귀 검사를 실시.
- **실제 Windows WanGP UI·GPU 무료 이미지 생성·저사양 성능/시간 및 모바일 실기 화면 검사는 미실시.**
