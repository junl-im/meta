# 곰같은여우의 AI 스튜디오 v0.30 — 첫 작품 모델 탐색·준비 확인 QA

작성일: 2026-11-06

## 목표와 범위

- 초보자용 **처음 실행 · 따라 하기** 화면에서 작업 분야를 고르고 모델을 검색·조회·선택·점검하는 흐름을 연결한다.
- 원본 WanGP `list_model_metadata`와 `get_model_availability` 및 현재 PC RAM/VRAM 읽기 경로만 사용한다.
- 기존 원본 프로그램의 모델 변경, 다운로드, 생성, 설정 변경, 큐 취소, 저장 파일 교체를 수행하지 않는다.
- 무료 로컬 제작을 기본으로 두고 GPT 감독은 명시적 동의 후 선택적으로만 호출한다.

## 변경된 초보자 흐름

1. **처음 실행 · 따라 하기**에서 영상·이미지·음성·3D 중 분야를 선택한다. 기본은 이미지다.
2. **첫 작품 모델 찾기**에서 이름 일부를 검색하고 **이 분야 모델 찾아보기**를 누른다. 최대 40개가 선택 메뉴에 나타난다. 나오지 않으면 검색어를 좁혀 다시 조회한다.
3. 모델을 직접 골라 **선택 모델·내 PC 준비 확인**을 누른다. 원본 모델 파일 준비 여부와 시스템 RAM·감지된 GPU VRAM을 구분해 보여준다.
4. 가능 여부가 확정되는 것은 아니다. 원본 **Media Generator**에서 생성 모델을 사용자가 다시 선택하고, 모델이 지원하는 작은 해상도·배치 1로 이미지를 시험한다. 다운로드가 필요하면 원본에서 직접 진행한다.
5. **작업 현황 · 갤러리**에서 실제 완료/오류 상태를 확인한 뒤 원본 갤러리에서 결과를 저장한다.

## 안전·정합성 역검수

- [x] 분야를 바꿀 때 이전 검색어·모델 선택·준비 결과를 지움.
- [x] 검색어 변경 또는 다른 모델 선택 뒤의 이전 준비 결과가 성공으로 오인되지 않도록 초기화함.
- [x] 원본 모델 API 응답의 표시·선택 목록을 한 번의 목록 조회로 생성함.
- [x] 빈 선택/조회 오류에도 GPU 생성이나 모델 다운로드를 시도하지 않음.
- [x] 원본 응답에서 파일 경로·토큰·예외 문자열을 표시하지 않음.
- [x] 임의의 최소 VRAM이나 속도·실행 성공을 추정하지 않음.
- [x] 원본 WanGP 코어/모델/설정을 보존하고 신규 SVG·외부 CDN을 추가하지 않음.
- [ ] Windows 16GB 실기기에서 공식 WanGP Manager 설치 후 플러그인 렌더링 확인.
- [ ] 실제 모델 목록 조회 및 GPU/VRAM 실측 확인.
- [ ] 작은 무료 이미지 1장 생성, 갤러리 저장과 소요 시간/성공 여부 기록.
- [ ] Android 세로/가로 레이아웃 및 오래 사용했을 때의 안정성 확인.

Linux Python 단위 테스트, 모의 Gradio 이벤트 연결, Windows CMD 해시/안전 계약을 자동 검사한다. 자동 테스트 통과는 Windows 또는 GPU 실기 시험 통과를 의미하지 않는다.
