# 곰같은여우의 AI 스튜디오 v0.26 — 모델 사전 점검 및 실기기 검수표

> 2026-11-05 개발용. `0.26.0-dev` 플러그인. **Windows 16GB / 저사양 GPU에서 실제 설치·이미지 생성 검증 전**. Linux 자동·모의 UI 검사와 실제 하드웨어 성능 시험을 혼동하지 마세요.

## 1. 사용 순서

1. **처음 실행 · 따라 하기**에서 이미지/영상/음성·음악/3D 등 첫 작품 분야를 선택합니다.
2. **모델 찾아보기**에서 해당 분야의 모델 필터가 따라 바뀌었는지, **무료 프롬프트 작업실**에서 분야가 맞는지 확인합니다. 이 연결은 UI 선택 상태만 바꾸며 실제 모델·설정·프롬프트 내용을 자동 적용하지 않습니다.
3. **모델 찾아보기**에서 원본이 제공한 모델 메타데이터를 확인하고 원하는 항목을 선택합니다.
4. 접이식 **이 모델, 내 PC에서 시작해도 될까요? · 사전 점검 (선택)**을 펼칩니다. 필요할 경우 Windows **작업 관리자 → 성능 → GPU**에서 읽은 전용 VRAM 수치를 직접 입력합니다. 자동으로 확인되지 않은 값은 직접 입력한 참고값으로 표시됩니다.
5. **사전 점검** 버튼을 누르면 원본 API의 모델 파일 준비 상태(제공한 경우), RAM 관측값, CUDA GPU VRAM 관측값을 분리해 표시합니다. 알 수 없는 항목은 **확인되지 않음**으로 남겨 둡니다.
6. 실제 생성을 원할 때만 **원본 무료 제작 화면**에서 직접 지원 모델·설정을 선택하고 소규모 테스트를 진행합니다. 사전 점검은 생성 가능 확인서가 아닙니다.

## 2. 사전 점검의 한계

| 확인 대상 | 표시 기준 | 보증하지 않는 것 |
| --- | --- | --- |
| 모델 목록·상세 | 원본 메타데이터 API가 제공한 항목 | 모델의 실제 로딩·생성 성공 |
| 모델 파일 준비 상태 | 원본 API가 명확히 알려준 상태만 표시 | 파일 전체의 작동·공간·의존성 충족 |
| 시스템 RAM | 현재 실행 PC에서 실제 관측된 값 | 가용 메모리 또는 작업별 최솟값 충족 |
| CUDA GPU 전용 VRAM | 시스템에서 읽힌 CUDA 장치별 값 | Windows GPU 이름만으로 추정한 전용 VRAM |
| 수동 VRAM 입력 | 사용자가 직접 확인했다고 입력한 참고 수치 | 검증된 하드웨어 정보 또는 실행 합격 판정 |

- 모델에 대한 고정된 VRAM 요구 수치를 임의로 만들지 않습니다. 모델·양자화·오프로딩·드라이버·실제 작업에 따라 필요한 메모리가 달라질 수 있습니다.
- 입력이 잘못됐거나 0·비정상 수치면 이를 성능 합격 근거로 활용하지 않습니다.
- **사전 점검 버튼은 읽기 전용입니다.** 자동 모델 다운로드, GPU 렌더 시작, 원본 생성 설정 변경, 클라우드 결제 또는 GPT 호출을 수행하지 않습니다.
- 원본 WanGP 파일과 기존 플러그인 설치 파일을 자동으로 덮어쓰거나 삭제하지 않습니다.

## 5. 개발용 자동 검증

저장소 루트에서 `python -m unittest discover -s WanGP-KR/tests -p 'test_*.py' -q`로 실행합니다. 모의 세션은 원본 API를 가정하여 오류 및 불완전 정보·UI 이벤트 연결만 검사합니다. **실제 WanGP·Gradio·GPU 작동을 검증하지 않습니다.**

후속 실기기 확인 때는 원본 지원 모델인지, 필요한 가중치 다운로드 용량과 라이선스, 생성 결과 경로, Windows 오류 로그를 별도로 기록하세요.
