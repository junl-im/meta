# 곰같은여우의 AI 스튜디오 — 처음 쓰는 분을 위한 사용 설명서

> **현재는 0.11.0 개발판.** 한국어 플러그인의 도움말과 모델 탐색 기능은 코드 작성 단계이며 Windows/WanGP 실제 실행 검증 전입니다. WanGP 설치에는 GPU 호환성이 필요합니다.

## 아직 WanGP를 설치하지 않았다면

먼저 [Windows 전체 설치 안내](FULL_INSTALL_WINDOWS_KO.md)를 확인하세요. 원본 WanGP가 없는 컴퓨터에서는 플러그인만 실행할 수 없습니다. 설치 도우미는 공식 WanGP Manager로 원본부터 설치하도록 안내합니다.

## 화면에서 가장 먼저 할 일

1. `곰같은여우의 AI 스튜디오` 탭을 엽니다.
2. **처음 실행 · 따라 하기**에서 작업 종류를 고르고, 필요하다면 PC 사양 버튼을 누르세요.
3. **무료 제작 화면으로 이동**을 누릅니다. GPT 로그인은 필요 없습니다.
4. 원본 화면에서 영상·이미지·음성·3D 중 모델을 고르고, 만들고 싶은 것을 문장으로 입력합니다.
5. 짧고 작은 설정으로 먼저 **생성**한 뒤 갤러리에서 결과를 확인합니다.

## 무료 프롬프트 작업실 — 처음부터 써 보기

1. **프롬프트 작업실**을 열고 영상·이미지·음성·음악·3D 중 작업 분야를 고릅니다.
2. 분위기와 시작 모드를 정합니다. 저사양 PC에서는 기본인 **절약**을 권장합니다.
3. 처음이라면 **처음이라면 예시 넣기**를 눌러 주제와 추가 조건을 자동으로 채워 보세요. 각 칸을 마음대로 수정할 수 있어요. 익숙하다면 처음부터 직접 적어도 됩니다.
4. **무료 프롬프트 만들기**를 눌러 문장 초안을 완성합니다.
5. **프롬프트 한 번에 복사**를 눌러 복사하고, 원본 제작 화면에 직접 붙여넣습니다. 클립보드 권한이 차단되면 직접 선택해 복사하세요.
6. 원본에서 실제 모델·프레임·해상도·파일 저장을 선택합니다.

비어 있는 주제로 만든 오류 안내 문구는 복사되지 않도록 막았습니다. **예시 넣기**는 생성 버튼이 아니라 텍스트 입력 보조 버튼입니다.

이 작업실은 인터넷이나 GPT 없이 **텍스트만 작성**합니다. 프롬프트를 복사해도 원본 입력칸을 자동으로 덮어쓰지 않습니다. 절약·균형·고품질은 시작 **안내**이지 GPU 설정을 자동 적용하는 기능이 아닙니다.

## 작은 화면에서 사용하기

- 모바일에서는 배너·상단 로고·작업 선택 버튼을 더 작게 표시합니다. 상단 탭은 좌우로 이동해 원하는 기능을 찾을 수 있습니다.
- 키보드 사용자에게는 선택한 버튼의 포커스가 표시됩니다. 움직임 줄이기를 설정한 운영체제에서는 작업 버튼의 움직이는 효과를 줄입니다.
- 원본 WanGP 자체 화면은 이 플러그인이 다시 만들지 않습니다. 실제 모바일 한 화면 적합성은 사용 중인 브라우저에서 별도 확인이 필요합니다.

## 무엇을 고르면 좋을까?

| 하고 싶은 일 | 처음 선택 |
|---|---|
| 그림 한 장 만들기 | **사진·그림** 도움말 → 원본 이미지 모델 |
| 사진을 움직이게 하기 | **짧은 영상** → 이미지→영상(I2V) |
| 말로 영상을 만들기 | **짧은 영상** → 텍스트→영상(T2V) |
| 목소리 또는 배경음 | **목소리·음악** → 지원 오디오 모델 |
| 사진으로 입체 물체 만들기 | **3D 만들기** → 3D 메시 모델 |
| 월드 탐험 | **움직이는 월드** → 지원 월드 모델 |
| 느리거나 오류가 뜰 때 | **저사양 설정**, **오류 해결** |
| 용어가 어려울 때 | **용어 풀이** |

## 헷갈리기 쉬운 핵심 버튼

- **도움말 주제**: 설명을 바꾸기만 합니다. 생성·다운로드·결제하지 않습니다.
- **컴퓨터 사양 확인하기**: 버튼을 눌렀을 때만 WanGP 실행 장치의 RAM·GPU·가능한 전용 VRAM을 읽습니다. 설정 변경·파일 저장·외부 전송은 하지 않습니다. 자동 확인 실패 시 작업 관리자의 수동 확인 방법을 안내합니다.
- **원본 모델 목록 읽기**: 설치된 WanGP의 모델 **정보**를 가져옵니다. 전체 모델을 한 화면에 다 늘어놓지 않고 40개씩 보여줍니다. 새로운 원본 모델도 자동 탐색 대상입니다.
- **원본 무료 제작 화면 열기**: 원본 WanGP로 이동합니다. 그곳에서 실제 모델/설정/생성을 선택합니다.
- **선택한 감독에게 요청하기**: 선택 기능입니다. Deepy Prime 설정과 사용자의 동의가 있을 때만 요청합니다. **GPT를 안 써도 기본 제작에는 지장이 없어야 합니다.**

## 처음 연습해 볼 프롬프트

**이미지**: `비 오는 밤, 작은 한국 골목의 따뜻한 카페, 창문에 비친 가로등, 수채화 느낌`

**짧은 영상**: `노을 진 바다 위로 작은 배가 천천히 지나간다. 카메라는 고정, 부드러운 물결, 차분한 색감`

처음엔 화질·길이보다 **한 번 완성해 보는 것**이 중요해요. 그래픽카드가 낮으면 생성 시간이 길어질 수 있습니다.

## 무료가 기본이라는 뜻

WanGP 소프트웨어의 라이선스 조건에서 허용되는 개인 사용과 지원 로컬 모델을 자기 PC에서 돌리는 경로는 GPT/Claude/외부 생성 API 연결이 필요하지 않습니다. 하지만 PC·GPU·전기·디스크 비용, 특정 모델의 개별 이용 조건은 별도입니다.

원하는 경우에만 Codex(GPT)를 Deepy Prime의 감독으로 선택할 수 있습니다. 단, **Showrunner의 자동 기획은 Deepy Prime이 필요**하고 로컬 감독 LLM의 실행 가능성은 사양에 따라 달라집니다.

## 도와 달라고 할 때 알려주면 좋은 것

- Windows와 RAM: 16GB(이미 확인됨)
- 작업 관리자의 **GPU 모델명 / 전용 GPU 메모리(VRAM)**
- 어떤 모델을 골랐는지, 어떤 버튼을 눌렀는지
- 오류 메시지 또는 화면 캡처

비밀번호·API 키·개인 음성·사진은 공개 GitHub에 올리지 마세요.
