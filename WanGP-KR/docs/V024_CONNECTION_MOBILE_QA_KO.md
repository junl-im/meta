# v0.24 모바일 오류 화면·원본 연결 3단계 검수표

> 2026-11-05 · 개발용. Linux 코드·모의 UI 검증과 실제 Windows/Android 기기 실행 검증을 구분합니다. 원본 WanGP와 GPU 생성 실기 테스트는 아직 실행하지 않았습니다.

## 구현 내용

- 처음 실행 → **문제가 생겼나요? 단계별 해결**에 오류 진단 보기와 함께 **입력 지우기** 버튼을 배치합니다. 기존 입력란·분류 결과를 함께 초기화하며 오류 원문을 결과로 다시 출력하지 않습니다.
- 모바일 740px 이하에서는 오류 결과의 글씨 크기·줄바꿈·패딩과 두 개 버튼의 줄바꿈을 조정합니다. 새 SVG나 그림 버튼 바깥에 중복 테두리를 추가하지 않습니다.
- **원본 연결 단계 확인 (읽기 전용)**은 사용자 클릭 시에만 실행합니다. ① 한글 화면의 해당 함수 실행 ② `list_model_metadata()` 반환 구조·개수 ③ 실제 생성의 별도 검증 필요를 구분합니다.
- 원본 모델 API 메서드 누락, 조회 중 예외, 예상 밖 반환 타입, 비정상 목록 항목, 빈 목록은 각각 다른 원인 확인 안내로 나타납니다. API 응답이 있더라도 모델 다운로드 완료 또는 GPU 생성 성공을 선언하지 않습니다.
- 원본 `list_queue`는 **호출하지 않고 메서드가 제공되는지만** 살핍니다. 원본 작업 내용·프롬프트를 읽거나 설정·드라이버·모델을 바꾸지 않습니다.

## 안전성 및 범위

1. 붙여넣은 오류 문장은 로컬 WanGP Gradio 이벤트를 통해 진단 함수에 전달됩니다. 암호·API 키·사적인 파일 경로는 미리 가린 뒤 입력하도록 안내합니다.
2. 분류와 연결 점검은 **사용자가 버튼을 누른 경우에만** 수행합니다. 로그 자동 수집·별도 파일 저장·외부 GPT/API 요청·원본 다운로드·기존 파일 삭제 없음.
3. Windows CMD 설치/점검 도우미의 플러그인 14개 파일 SHA-256은 소스 `5afdf5e1f78f40da95c3528cce2cf6963e07bd7b`에 고정합니다. 복사한 파일도 재검사하고 기존 설치 폴더를 자동 덮어쓰지 않습니다.

## Windows RAM 16GB 실기기 시험 — 미실시

| 단계 | 검사 항목 | 기록할 사실 |
| --- | --- | --- |
| 1 | 공식 WanGP Manager에서 원본 설치와 Start WanGP | 원본 실행/오류, Windows 빌드, 실제 설치 경로 |
| 2 | `check_studio_windows.cmd` 실행 후 SHA-256 14개 대조 | 기준 `5afdf5e`, 일치/불일치, 실패 원인 |
| 3 | 브라우저에서 한글 탭과 4종 WebP 원화 로딩 | 글자·그림 깨짐, 모바일/PC 레이아웃 |
| 4 | 오류 진단에 예시 `CUDA out of memory` 입력 후 `입력 지우기` | 입력과 이전 결과가 함께 비워지는지 |
| 5 | 원본 연결 단계 확인 버튼 누르기 | UI 함수 실행, 모델 API 조회 응답/실패, 생성 미검증 표기 |
| 6 | 원본 WanGP 작업 큐의 작업이 유지되는지 확인 | 새 작업 제출·기존 작업 취소 없음 |
| 7 | GPU/VRAM 용량과 모델 요구 사양 직접 확인 후 무료 작은 이미지 한 장 제작 | GPT 사용 안 함, 생성 시간, RAM/VRAM, 파일 저장 확인 |
| 8 | 360×640·390×844·모바일 가로 및 일반 PC 화면 검수 | 가로 넘침·버튼 터치·입력 초점·설명 잘림 여부 |

**중단 기준:** 원본 작업 변경, 기존 플러그인 자동 덮어쓰기, 개인정보 로그 결과 출력, 오류 버튼 클릭만으로 외부 API 호출 또는 모델 다운로드가 있으면 즉시 중단합니다.

## 개발 검증

- `python -m unittest discover -s WanGP-KR/tests -p 'test_*.py'`로 읽기 전용 모델 API 호출 수·예외 처리·로그 지우기·모의 Gradio 이벤트·모바일 CSS·Windows 설치 체크섬을 검사합니다.
- 소스 고정 커밋: `5afdf5e1f78f40da95c3528cce2cf6963e07bd7b` (한글 플러그인 배포 바이트 기준).
- PR #130은 **Draft·미병합·미배포**로 유지합니다. 실제 Windows 16GB·GPU 최초 생성 성능을 검증하기 전 정식 배포로 표시하지 않습니다.
