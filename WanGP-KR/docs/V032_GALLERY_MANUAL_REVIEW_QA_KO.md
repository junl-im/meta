# 곰같은여우의 AI 스튜디오 v0.32 — 결과 확인·초보자 QA

작성일: 2026-11-06

## 새 흐름

1. 원본 **Media Generator**에서 무료 로컬 모델을 선택해 사용자가 직접 생성 작업을 진행한다. 이 플러그인은 생성·다운로드·큐 변경을 수행하지 않는다.
2. 한국어 탭 **작업 현황 · 갤러리**에서 현재 큐를 새로 조회한다. 실행·대기·취소 중 상태가 보인다면 기존 v0.31 안내를 따른다. **큐가 비어도 성공 여부는 알 수 없다.**
3. **원본 WanGP 제작·갤러리 화면으로 이동**으로 원본 화면을 열어 결과/오류를 직접 본다.
4. 한국어 탭으로 돌아와 접힌 **결과 확인 · 직접 점검**에서 `원본 갤러리에 결과가 보임` / `원본에 오류가 표시됨` / `갤러리에 결과가 보이지 않음` 중 본 사실을 선택한다. 모르면 `아직 확인 전`으로 둔다.
5. 결과가 보인 경우에만 실제 저장·내보내기 후 **내 PC에서 결과 파일을 열어 봤어요**를 체크한다. **내 확인 결과 안내 보기**에서 다음 행동을 읽는다.

## 거짓 완료 표시 방지

- 사용자 체크는 사용자 자신의 확인 내용이며 스튜디오의 원본 API·디스크 자동 검사 결과가 아니다.
- 갤러리 결과만 보이면 **파일 확인 남음**, 결과와 로컬 파일 열기를 모두 체크하면 **사용자가 직접 확인한 항목**으로 표시한다.
- `아직 확인 전`·원본 오류·결과 없음인데 파일 열기 체크가 켜지면 **서로 맞지 않음**을 안내한다.
- 큐 갱신은 기존 상세 안내 외에 갤러리 선택, 파일 열기 체크, 과거 확인 안내를 **초기화**한다. 이전 작업의 결과가 다음 작업 성공으로 남지 않는다.
- 원본 큐의 완료된 작업/실시간 진행률/갤러리 결과 조회 API가 있다고 가정하지 않는다. 자동 중복 제출·재시도·생성·취소 없음.
- 도움말에서 큐만으로 성공 판단을 암시하던 문장을 수정하고 갤러리·오류 화면 확인을 분리했다.

## 코드 역검수

- [x] 결과 확인 함수는 세션·디스크·네트워크를 호출하지 않음.
- [x] 사용자 입력을 그대로 출력하지 않고 미리 정한 선택지에만 응답.
- [x] 확인 전·갤러리 표시·오류·결과 없음·모순 체크 테스트.
- [x] 큐 새로고침마다 원본 목록 API 1회, 수동 검증 세 항목 초기화.
- [x] 도움말 오류 표현 수정 및 회귀 검사.
- [x] 원본 코어·이미지/영상 생성 처리·개인 파일·GPU 설정 변경 없음, 무료 로컬 기본/GPT 선택 유지, 신규 SVG 없음.
- [ ] 실제 Windows 16GB / 저사양 GPU에서 원본 WanGP 실행·갤러리 이동 및 수동 점검 흐름 검증.
- [ ] GPT 없이 작은 이미지 1장 생성·내보내기·파일 열기·소요 시간·VRAM 측정.
- [ ] 실패·취소·Android 좁은 화면에서 체크 흐름과 글씨 배치 실기기 검증.
