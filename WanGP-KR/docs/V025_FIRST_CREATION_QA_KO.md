# v0.25 첫 무료 작품 4단계 안내·Windows 실기기 검수표

> 2026-11-05 · 개발 초안. 실제 Windows 16GB PC / GPU / 모바일 브라우저에서 아직 시험하지 않았습니다. Linux 유닛 테스트는 실제 무료 이미지 생성이나 WanGP 원본과의 성능 동등성을 입증하지 않습니다.

## 사용자가 따라가는 순서

1. 공식 **WanGP Manager → Start WanGP**를 눌러 원본을 실행하고 한글 **곰같은여우의 AI 스튜디오** 탭을 활성화합니다.
2. **처음 실행 · 따라 하기** 탭에서 분야(처음 시작 / 사진·그림 / 짧은 영상 / 목소리·음악 / 3D 만들기)를 선택합니다.
3. **첫 무료 작품 · 단계별 따라 하기**에서 `① 원본 실행 확인`부터 `④ 결과 확인·저장`까지 **수동으로** 선택해 내용을 확인합니다.
4. 필요하면 **내 PC 사양 살펴보기**를 눌러 RAM·GPU를 확인합니다. **모델 찾아보기**에서 해당 모델과 필요한 VRAM·라이선스를 조사합니다.
5. **프롬프트 작업실**에서 문장을 준비합니다. 생성 자체는 **원본 무료 제작 화면 열기 → Media Generator**에서 사용자가 직접 진행합니다. GPT/Deepy Prime은 필수가 아닙니다.
6. **작업 현황 · 갤러리**에서 원본 큐 상태를 조회하고, 실제 완료된 경우에만 원본 갤러리에서 저장합니다.

## 구현한 동작과 구현하지 않은 동작

- 작업 종류 5종 × 진행 단계 4종 = **20개 안내 조합**을 한국어 고정 문구로 표시합니다. 해당 분야가 원본에 지원되지 않을 수 있다는 점, 특히 3D 및 영상의 높은 VRAM 요구를 안내합니다.
- 분야 또는 단계를 바꾸면 **같은 화면의 안내 문구만** 전환합니다. 긴 기존 도움말은 기본 접힘이며 사용자가 원할 때만 펼칩니다.
- 알 수 없는 작업 종류·단계는 안전한 초기 안내로 돌아갑니다. 임의 사용자 문자열을 Markdown/HTML로 출력하지 않습니다.
- 자동 다음 단계 진행, 모델 자동 선택/다운로드, 생성 버튼 원격 실행, GPU/RAM 설정 적용, 갤러리 파일 자동 저장, GPT 전송은 **구현하지 않았습니다**. 완료 상태를 검증한 척하지 않습니다.
- 신규 PNG/WebP/SVG는 추가하지 않았습니다. 기존 독립 WebP 4종과 PNG 아이콘·배너를 그대로 재사용합니다.

## 실제 Windows RAM 16GB 검수 — 전부 미실시

| 번호 | 확인할 항목 | 기록할 결과 |
| --- | --- | --- |
| 1 | Windows 에디션/빌드, CPU, RAM 16GB, GPU 이름과 실제 전용 VRAM 확인 | 장비 정보·전용 VRAM 수치(추정 금지) |
| 2 | 공식 Manager 원본 설치, `Start WanGP`, 한글 탭 초기 화면 확인 | 원본 버전/설치 위치/로딩 오류 |
| 3 | `check_studio_windows.cmd`로 14개 파일 SHA-256 대조 | `f9bcaed` 고정 기준/일치·누락·불일치 |
| 4 | 모바일 360×640 / 390×844 / 가로 화면에서 첫 작품 단계 선택 | 길이·줄바꿈·터치·가로 넘침 |
| 5 | 5개 분야를 바꾼 뒤 각각 4개 단계의 한국어 문구 변경 확인 | 단계·분야별 20개 조합, 오류·누락 |
| 6 | 사용자 선택 전후 원본 모델·VRAM·큐가 그대로인지 확인 | 외부 요청 없음/자동 생성 없음 |
| 7 | GPT 없이 원본에서 **지원 가능한 작은 이미지 한 장** 직접 생성 | 모델명·다운로드 여부·성공/오류·시간·최대 RAM·VRAM |
| 8 | 원본 큐 완료 확인 및 실제 이미지 파일 갤러리 저장 | 파일 형식·저장 경로·재열기 성공 여부 |
| 9 | 성능 여유가 실제로 확인된 경우에만 짧은 영상/음성/3D를 별도 시도 | 모델별 실행 가능 여부·품질·메모리와 시간 |

**중단 기준:** 기존 플러그인을 지우거나 덮어쓰라는 안내, 동의 없이 외부 AI 전송, 사용자 조작 없이 원본 작업 제출, 테스트 범위를 벗어난 GPU 설정 변경, 설치 파일 SHA-256 불일치가 발견되면 더 진행하지 않습니다.
