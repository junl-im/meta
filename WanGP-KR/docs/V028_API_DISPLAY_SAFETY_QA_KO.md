# v0.28 원본 API 표시 보호 및 Windows 실기기 역검수

> 2026-11-05 개발 초안. 플러그인 `0.28.0-dev`. 현재 Linux 모의 응답 단위 검사 단계이며 실제 Windows 16GB PC 및 GPU 생성은 검증되지 않았습니다.

## 변경 내용

1. 원본 모델 목록·모델 상세·작업 큐에서 조회 예외가 생겨도 예외 원문을 화면에 표시하지 않습니다. 연결 상태는 원본 WanGP에서 직접 확인하도록 안내합니다.
2. 원본 `get_model_availability()`의 응답은 임의 내부 경로와 부가 필드를 표시하지 않고, `files_ready`가 참/거짓임이 확인될 때만 그 값만 출력합니다. 응답이 불완전하다면 준비 여부 미확인으로 표시합니다.
3. 원본 메타데이터와 큐 상태에 포함된 제어문자·개행을 한 줄로 합치고 글자 수를 제한하여 화면 목록이 깨지지 않도록 합니다.
4. 원본에서 제공하지 않는 GPU 실행 성공·최소 VRAM·렌더링 속도는 계산하거나 추정하지 않습니다. 작업 내용(prompt)은 기존처럼 사용자가 노출 옵션을 선택한 경우에만 표시됩니다.

## 검증

- Python 자동 테스트: `python -m unittest discover -s WanGP-KR/tests -p 'test_*.py' -q`
- 원본 API의 예외 메시지에 파일 경로·토큰 문구가 있어도 결과 화면에 나타나지 않는지 확인.
- 모델 파일 정보 응답에 로컬 경로·자격 증명이 있어도 `files_ready` 외에는 숨기는지 확인.
- 잘못된 목록 형식과 개행 포함 모델·작업 상태를 안전하게 처리하는지 확인.
- Windows 전체 설치 도우미의 고정 GitHub 커밋 및 14개 파일 SHA-256 값이 현재 플러그인과 일치하는지 확인.

## 실제 사용자 PC에서 아직 해야 할 일

- Windows 16GB 환경에서 공식 WanGP Manager 설치와 첫 시작 확인.
- 한글 탭의 목록·상세·큐 조회, 네 종류의 PNG/WebP 이미지, 화면 크기와 접근성 확인.
- 원본에서 지원하는 가벼운 모델로 실제 무료 로컬 이미지 1장 생성과 결과 저장 시간·메모리 기록.
- 설치 검증·모의 API 테스트가 통과해도 GPU 생성이 통과했다고 표시하지 않기.

> 이 변경은 조회 결과의 **화면 표시**만 다룹니다. 원본 모델 파일, 가중치, 큐의 항목, 원본 설정·업스트림 API는 수정하지 않습니다.
