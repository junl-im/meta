# v0.12 검수표 — Windows RAM 16GB · 저사양 GPU

이 문서는 **실제 Windows 실기기 테스트를 수행할 때** 작성한다. Linux 기반 Python 단위 테스트와 정적 검사는 Windows GUI/GPU 테스트를 대신하지 않는다.

## 실기기 준비

1. Windows 10/11 64비트, 시스템 RAM 및 GPU 이름/VRAM을 기록한다. 기기에 적힌 VRAM과 공유 GPU 메모리를 혼동하지 않는다.
2. GPU 드라이버, 여유 디스크 공간, WanGP 공식 Manager 버전, 설치 경로를 기록한다. 공개 저장소에는 개인 경로나 장치 식별자를 올리지 않는다.
3. `scripts/install_studio_full_windows.cmd`를 실행한다. 공식 Manager 해시 검증 성공, 신규 플러그인 준비, 설치 경로 확인, 기존 파일 미덮어쓰기를 각각 확인한다.
4. 공식 Manager의 Start WanGP로 실행 후 Apps & PlugIn Manager에서 한글 스튜디오를 활성화한다. 바탕화면 바로가기 아이콘 및 최초 실행을 확인한다.
5. **무료 로컬 기본**에서 네 작업 카드가 모두 표시되고 선택 시 다른 분야의 도움말이 정상 표시되는지 확인한다. GPT 동의는 끈 상태를 유지한다.

## 성능 비교 기준

동일한 WanGP 원본 커밋, 모델, 해상도, 프레임 수, 시드, 샘플링 옵션으로 **원본 단독과 한글 스튜디오 활성 상태**를 번갈아 실행한다. 첫 실행 모델 로딩과 두 번째 실행 결과를 구분해 기록한다.

- 시작 시 GPU VRAM 점유량(MB), 최고 점유량(MB)
- 작업 총 소요 시간(초), 오류/완료 여부
- 생성 결과 파일 형식과 출력물 존재 여부
- 동일 시드 비교 시 화질 및 결과 차이
- 장시간 반복 실행 후 RAM/VRAM 누수 여부

**현재 판정: 코드 및 모의 UI 테스트만 수행됨. Windows 16GB PC의 실제 설치·GPU 생성·성능 우위는 주장하지 않는다.**
