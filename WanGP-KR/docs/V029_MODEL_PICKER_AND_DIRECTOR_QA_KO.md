# v0.29 모델 목록 클릭 선택 · 감독 오류 보호 및 실기기 검수

> 2026-11-05 개발 초안. 플러그인 `0.29.0-dev`. Linux 단위·모의 UI 테스트와 실제 Windows 16GB PC의 설치·GPU 렌더 테스트는 별개입니다.

## 첫 작품 시작 동선

1. 처음 실행 탭에서 영상·이미지·음성/음악·3D 중 분야를 직접 선택합니다. 무료 로컬 작업이 기본이며 GPT는 비활성 상태입니다.
2. 모델 찾아보기 탭에서 해당 분야의 원본 모델 목록을 조회합니다. **텍스트 목록과 클릭 선택 메뉴는 원본 API를 한 번 읽어 함께 만듭니다.**
3. **조회한 목록에서 모델 선택**에 나온 모델을 클릭하면 모델 ID 입력란에 원본 ID가 채워집니다. 검색어·페이지를 바꾸고 다시 조회하면 선택과 ID 입력란은 지워집니다. 필요한 경우 원본 ID를 직접 입력할 수도 있습니다.
4. 모델 상세·첫 실행 확인표는 읽기 전용입니다. 실제 모델 선택·다운로드·생성·저장 작업은 원본 WanGP의 Media Generator에서 사용자가 직접 진행해야 합니다.
5. 생성 실패 시 처음 실행 탭의 **문제가 생겼나요?**에서 상황별 도움말과 수동 오류 진단을 확인합니다. 원본 오류에 토큰·개인 경로가 있으면 입력 전에 가립니다.

## 선택형 감독 오류 보호

- 사용자가 감독 기능을 명시적으로 선택하고 동의한 경우에만 기존 Deepy Prime API로 호출합니다.
- 원본 Deepy의 연결 실패·실행 오류·출력 항목 이름에 민감 문자열이 있을 수 있으므로 한글 화면에는 안전한 일반 안내만 표시합니다. 오류 상세는 원본 Deepy 화면에서 확인합니다.
- 완료 안내에서도 내부 결과 이름·파일 경로를 출력하지 않습니다. 무료 로컬 작업은 독립적으로 계속 이용할 수 있습니다.

## 자동 검사 및 남은 검수

- `python -m unittest discover -s WanGP-KR/tests -p 'test_*.py' -q`
- 목록 조회 API가 단 한 번 호출되는지, 분류/검색/페이지 선택 범위 안의 ID만 표시되는지, 예외 시 선택지가 비워지는지 확인.
- 실제 원본 생성 설정 변경·모델 다운로드·GPT 자동 호출이 없는지 확인.
- 원본 감독 오류와 결과 이름에 민감 문자열을 넣은 모의 테스트에서 이를 화면에 재출력하지 않는지 확인.
- Windows 16GB 사용자의 실제 Manager·Gradio 탭 동작과 GPU 무료 이미지 1장 생성·갤러리 저장·시간/VRAM, Android 세로/가로 화면은 **아직 미검증**. 완료를 주장하지 않기.

> Windows 설치 도우미는 원본 엔진을 유지하고 기존 플러그인을 자동 덮어쓰지 않습니다. 모델별 요구 사양과 라이선스는 원본에서 확인하세요.
