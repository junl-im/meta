## A. Windows 처음 설치 (사용자 PC: RAM 16GB, GPU 모델 미확인)

- [ ] 별도 설치된 WanGP가 없는 Windows 64비트 환경에서 단일 설치 도우미 실행
- [ ] 공식 Manager 실행 파일과 체크섬 검증 성공
- [ ] 설치 전 GPU 이름·RAM·디스크 여유 공간 안내 표시
- [ ] 공식 WanGP Manager에서 GPU 프로필을 확인한 후 원본 엔진·의존성 설치 완료
- [ ] 한국어 플러그인 신규 설치 성공, 필수 9개 파일 존재
- [ ] 설치 실패를 모의한 경우 기존 plugins 폴더 유지 및 불완전한 플러그인 자동 노출 없음
- [ ] 설치 후 임시 작업 폴더가 남지 않는지 확인 (실패 시 사용자 확인 후 수동 정리)
- [ ] 전용 PNG·ICO·바탕화면 바로가기 표시 및 실제 실행 확인
- [ ] 원본 Apps & PlugIn Manager에서 플러그인 활성화 및 재시작 성공

## B. 무료 제작과 선택 감독

- [ ] GPT/외부 API 로그인 없이 원본 이미지 모델로 최소 1개 생성
- [ ] 지원되는 경량 영상 모델을 선택해 짧은 영상 1개 생성 (GPU 부적합 시 미지원으로 기록)
- [ ] 모델 탐색·상세 상태·공용 큐 조회 동작
- [ ] 프롬프트 예시 채우기→수정→생성→복사→원본 입력 동작
- [ ] GPT 동의 체크를 켜지 않으면 감독 작업이 전송되지 않음
- [ ] 작업 결과는 원본 갤러리에서 저장·열기 가능

## C. 화면·접근성
