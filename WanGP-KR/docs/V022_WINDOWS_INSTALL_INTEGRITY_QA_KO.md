# v0.22 — Windows 첫 설치 복사 무결성·무료 생성 실기기 검수

> **개발용 검수 문서:** 설치 도우미의 복사 후 해시 재확인 코드를 추가했습니다. 실제 사용자 Windows 16GB PC에서 공식 Manager·설치·무료 GPU 생성을 실행한 결과는 아직 없습니다.

## 첫 설치 흐름

1. [Windows 전체 설치 도우미](../scripts/install_studio_full_windows.cmd)를 내려받습니다. 새로운 PC에서는 공식 WanGP Manager 파일과 SHA-256을 검증한 뒤 사용자가 직접 설치를 완료합니다. 공식 Manager의 설치 완료 여부는 도우미에서 `wgp.py`와 `plugins` 구조로 확인합니다.
2. 한국어 플러그인 **14개 필수 파일**을 GitHub의 고정 소스 커밋 `53f90051e4c1983fe9e5cbaa9f98bfead398d0c3`에서 각각 다운로드하고 SHA-256을 확인합니다.
3. 사용자가 한글 스튜디오 추가를 승인하면 **원본 설치 폴더 아래의 독립 임시 폴더**에 복사합니다. 기존 `plugins/wan2gp-gomfox-studio` 폴더는 덮어쓰지 않습니다.
4. 새 단계: 임시 폴더에 필수 파일 14개가 존재하는지 확인한 후, **각 파일의 SHA-256을 다시 검사**합니다. 다운로드 때 검증된 값과 하나라도 다르거나 해시 검사가 실패하면 **원본 plugins 폴더로 이동하기 전에 중단**합니다.
5. 모두 일치하고 다른 설치가 먼저 만든 대상 폴더가 없을 때만 `plugins/wan2gp-gomfox-studio`로 이동합니다. 시그니처 아이콘과 바탕화면 바로가기는 가능한 경우 사용자 동의 후 진행합니다.
6. [읽기 전용 설치 점검](../scripts/check_studio_windows.cmd)으로 **설치 뒤 14개 해시**를 다시 대조할 수 있습니다. 이 점검은 기존 설치를 고치거나 GPU 생성을 실행하지 않습니다.

## 실패·복구 분기

| 상황 | 도우미의 안전 동작 | 다음 확인 |
| --- | --- | --- |
| 공식 Manager 다운로드 또는 체크섬 오류 | 원본 Manager 실행 전 중단 | 네트워크 및 공식 릴리스·SHA-256 파일 확인 |
| 원본 설치 경로가 없음 | 플러그인 설치 중단 | 공식 Manager의 설치 완료 및 `wgp.py` 확인 |

| 다운로드 파일 해시 불일치 | 파일 복사 전 중단 | 새 다운로드 후 재검증. 검증 우회 금지 |
| 임시 복사 파일 해시 불일치 | 최종 플러그인 폴더 이동 전 중단 | 실패 파일 이름·임시 폴더 경로 기록. 자동 삭제 금지 |
| 앱 실행 또는 작은 이미지 생성 실패 | 설치 도우미만으로 GPU 성공 판정하지 않음 | 원본 요구 사양·작업 관리자 전용 VRAM·지원 모델 확인 |

## Windows 16GB 실제 사용자 검수표

- [ ] 공식 Manager 다운로드·SHA 검증 및 원본 설치 정상 종료
- [ ] 새 플러그인 14개 다운로드 체크섬 확인
- [ ] 임시 폴더 복사 후 14개 SHA-256 재확인 및 최종 이동 확인
- [ ] 기존 플러그인 충돌 시 **덮어쓰기 없는 중단** 확인 (테스트를 위해 실제 사용자 파일 삭제 금지)
- [ ] 별도 읽기 전용 CMD에서 원본 구조와 플러그인 SHA-256 통과
- [ ] WanGP Manager의 Start WanGP로 브라우저에서 한국어 탭·4종 WebP 원화 정상 표시
- [ ] 원본 모델 목록에서 실제 GPU 지원 모델을 선택해 **GPT 없이** 작은 이미지 1장 생성 후 저장 확인
- [ ] 작업 관리자 VRAM 최고치, GPU 종류, 생성 시간 및 오류 코드를 [v0.20 오프라인 기록장](V020_WINDOWS_SMOKE_WORKBOOK.html)에 기록
- [ ] 모바일·PC 화면의 버튼/탭 잘림, 원화 원본 비율, 중복 테두리, SVG 신규 사용 여부 점검

## 이번 자동 검사 범위

- 설치 스크립트 정적 검사: **다운로드 해시 14개 = 임시 복사 재검증 해시 14개 = 로컬 플러그인 실제 바이트 SHA**.
- 재검증의 실행 순서가 `robocopy` 이후·최종 `move` 이전인지 확인하며, 실패 분기에 삭제·강제 덮어쓰기가 없는지 확인합니다.
- 실제 CMD/PowerShell/WanGP Manager, GPU 성능, Windows 그래픽 표시, Android 화면은 Linux 테스트로 확인할 수 없습니다. **실제 성공으로 보고하지 않습니다.**

**보호 원칙:** 원본 WanGP 코어·모델·설정·기존 플러그인·사용자 데이터를 그대로 유지. 새 SVG 없음. 무료 로컬 제작 기본, GPT 감독은 명시적 선택. GitHub PR은 Windows 실기기 검증 전까지 Draft로 유지.
