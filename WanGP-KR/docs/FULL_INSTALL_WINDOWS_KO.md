# 곰같은여우의 AI 스튜디오 — Windows 전체 설치 안내

> **2026-11-04 v0.13 개발용 설치 도우미**입니다. 설치 코드·체크섬은 검증했지만, 사용자의 Windows 컴퓨터에서 처음부터 끝까지 실제 실행 검증한 상태는 아닙니다. 실행 전 중요 파일을 백업해 주세요.

## 목표

**원본 WanGP 프로그램 + Python/필수 라이브러리 + 한글 스튜디오 플러그인**을 설치합니다. 원본 WanGP Community License 2.0과 각 AI 모델 라이선스는 그대로 적용합니다.

**모든 AI 모델을 한꺼번에 받지는 않습니다.** 모델별 가중치가 매우 클 수 있으므로 원본 WanGP에서 사용할 모델을 선택할 때 다운로드하는 방식입니다. 이게 기능을 삭제하는 것은 아닙니다.

## 시작 전 준비

- Windows 64비트 컴퓨터
- 인터넷 연결, 설치 및 모델 다운로드에 필요한 충분한 SSD/HDD 여유 공간
- 가능하면 [작업 관리자 → 성능 → GPU]에서 GPU 모델과 전용 VRAM 확인
- 시스템 RAM 16GB는 확인했지만, 지원 가능한 실제 영상 모델과 성능은 GPU에 따라 다릅니다.
- 공식 원본: https://github.com/deepbeepmeep/WanGP
- 공식 설치 관리자: https://github.com/deepbeepmeep/WanGP/releases/latest/download/WanGPManager.exe

## 가장 쉬운 설치 순서

1. **추천 방법: [전체 설치 도우미 파일](https://github.com/junl-im/meta/blob/feat/wangp-kr-planning-20261101/WanGP-KR/scripts/install_studio_full_windows.cmd)**에서 **Download raw file**을 눌러 `install_studio_full_windows.cmd` 파일 하나를 저장합니다. 코드를 먼저 확인할 수 있습니다. Windows 보안 경고를 무조건 무시하지 말고 출처를 확인하세요.
   - **다른 방법:** [전체 프로젝트 ZIP 받기](https://github.com/junl-im/meta/archive/refs/heads/feat/wangp-kr-planning-20261101.zip) → 압축 풀기 → `WanGP-KR/scripts/`에서 같은 설치 파일을 사용해도 됩니다.
2. 저장한 설치 도우미 파일을 **더블클릭**합니다. 외부 관리자 권한이나 이미 설치된 Git/Python이 필요하지 않도록, 공식 Manager를 이용하는 경로입니다. 기본 Windows의 curl.exe·PowerShell은 필요합니다. 설치 전 **GPU 이름·RAM·기본 드라이브 여유 공간**을 참고용으로 보여줍니다. 이것은 호환성 합격 판정이 아니며 GPU 설정을 변경하지 않습니다.
3. 설치 도우미는 한글 플러그인 코드 8개·PNG 2개·분야별 WebP 4개, 총 **14개 파일**을 GitHub의 **고정 커밋(`86e3390`)**에서 내려받아 각각 SHA-256을 확인합니다. 설치 스크립트 주변의 미검증 파일을 재사용하지 않습니다. 그다음 공식 **WanGPManager.exe**와 **WanGPManager.exe.sha256**을 받아 검증하며, 검사 실패 시 실행하지 않습니다.
4. 질문이 나오면 **Y**를 선택해 공식 WanGP Manager를 실행합니다. Manager의 **Install** 메뉴에서 전체 WanGP를 설치하고 GPU에 맞는 추천 프로필을 확인합니다.
5. 가능하면 설치 도우미 화면에 표시된 기본 폴더를 WanGP 설치 위치로 선택하세요. 다른 경로도 가능하지만 이후 폴더를 한 번 입력해야 합니다.
6. Python 및 필요한 라이브러리 설치가 모두 끝나면 **WanGP Manager를 닫습니다**. 설치 도우미가 다음 단계로 넘어갑니다.
7. 한글 플러그인 추가 질문이 나오면 경로를 확인한 뒤 **Y**를 누릅니다. 이미 플러그인 폴더가 있다면 덮어쓰지 않고 중단합니다.
8. 설치가 끝나면 **바탕화면 바로가기 생성**을 선택할 수 있습니다. 아이콘 원화 검증에 성공하면 Windows 표준 `.ico` 형식으로 변환하여 전용 아이콘을 지정합니다. 설치 폴더에 공식 `scripts\run.bat` 파일이 확인될 때만 제안하며, 기존 바로가기는 덮어쓰지 않습니다. 이 실행 방식이 Manager가 설치한 환경과 맞지 않으면 **WanGP Manager → Start WanGP**를 사용하세요.
9. WanGP를 실행한 뒤 원본 **Apps & PlugIn Manager**에서 **곰같은여우의 AI 스튜디오**를 찾아 활성화합니다. 원본에서 재시작을 요구하면 따라 주세요.
10. 새 한국어 탭을 열면 **무료 제작 · 시작**이 첫 화면입니다. 영상·이미지·음성/음악·3D 원화 카드를 눌러 설명을 확인하세요. 처음이라면 첫 화면의 **시작 전 확인**에서 앱 상태와 PC 사양을 확인한 뒤 무료 제작 화면으로 이동합니다.

## v0.13 시작 전 확인

- 원화 파일이 없거나 손상됐을 때 색상 카드로 대체하는 표시 안전 장치를 보강했습니다.
- **스튜디오 준비 상태 확인**은 사용자가 직접 눌렀을 때만 원본 모델 정보와 플러그인 자산에 접근합니다. 실제 영상·이미지 생성이나 GPU 호환 여부의 합격 판정은 아닙니다.
- 실행 중 새 모델을 다운로드하지 않으며 GPT·유료 생성 API를 요구하지 않습니다. 구체적인 검수 범위는 [v0.13 점검 안내](V013_RUNTIME_CHECK_KO.md)를 참고하세요.

## v0.12 전용 원화와 첫 화면

- 네 분야는 각각 독립적인 WebP 그림 버튼으로 나타납니다. 파일이 누락되면 기존 색상 버튼을 표시하는 코드가 있지만, 정상 설치에서는 필수 4장을 모두 검증합니다.
- 온라인 연결이 필요한 구간은 공식 Manager 및 위 14개 설치 파일 다운로드입니다. 이후의 기본 로컬 제작에 GPT 또는 유료 생성 API가 필수는 아닙니다.
- 브라우저 없이 디자인을 먼저 보고 싶다면 [오프라인 미리보기](V012_VISUAL_PREVIEW.html)를 엽니다. 실제 설치 성능은 [Windows 16GB 검수표](V012_WINDOWS16_QA_KO.md)에서 확인합니다.

## v0.11 설치 실패 복구와 모바일 화면 정리

- 한글 플러그인을 원본 WanGP 설치 폴더 바로 아래의 별도 임시 폴더에 먼저 복사하고, v0.13에서는 필수 14개 파일이 모두 있는지 확인한 다음에만 원본 plugins 폴더로 이동합니다. 기존 플러그인 파일은 덮어쓰지 않습니다.
- 복사나 이동에 실패하면 원본 WanGP 설치와 기존 플러그인 폴더를 그대로 두고 중단합니다. 임시 작업 폴더가 남을 수 있으므로 오류 화면에 위치를 안내합니다. 자동 삭제는 하지 않습니다.
- 이미 한글 스튜디오가 있는 경우에는 이전처럼 덮어쓰기 없이 중단합니다. 이번 개선은 안전한 신규 설치 경로이지 자동 업데이트 기능이 아닙니다.
- 한국어 UI는 좁은 모바일 화면에서 배너·로고·분야 버튼의 크기를 줄이고 탭 가로 스크롤을 개선했습니다. 화면 높이가 낮은 경우의 추가 축소, 키보드 포커스 표기, 움직임 줄이기 설정을 지원합니다.
- Python 문법 및 모의 UI 이벤트 연결·설치 스크립트 정적 안전 검사만 완료했습니다. **실제 Windows/브라우저 표시·성능/그래픽 화질 검증은 아직 대기 중**입니다.

## v0.10 처음 사용자 프롬프트 예시

- 한글 스튜디오의 **프롬프트 작업실**에서 제작 분야를 고르고 **처음이라면 예시 넣기**를 누르면, 주제와 추가 조건을 편집할 수 있는 텍스트로 채웁니다.
- 영상·이미지·음성/음악·3D에 서로 다른 예시가 있으며, 사용자가 수정한 후 **무료 프롬프트 만들기**를 눌러 초안을 만듭니다.
- 빈 주제로 만든 안내 문구를 실수로 복사하는 동작을 막았습니다.
- 버튼은 네트워크/GPT/GPU를 호출하지 않고, 원본 프롬프트나 모델 설정을 자동 변경하지 않습니다.
- 단일 설치 파일이 최신 예시 기능을 받도록 고정 코드 커밋과 SHA-256을 갱신했습니다.
- Python 문법·예시 4종은 검증했으나, 실제 Windows 브라우저의 버튼/클립보드 동작은 아직 검증 전입니다.

## v0.9 여우·곰 시그니처 아이콘

- [원본 전용 PNG](https://github.com/junl-im/meta/blob/feat/wangp-kr-planning-20261101/WanGP-KR/assets/gomfox-studio-icon.png)를 플러그인 파일과 함께 고정된 GitHub 커밋에서 다운로드하고 SHA-256을 확인합니다. SVG는 사용하지 않습니다.
- 한글 플러그인을 신규 설치할 때 검증된 PNG를 플러그인 폴더에 넣어 **프로그램 상단에도 표시**합니다.
- Windows 자체 제공 **PowerShell + .NET System.Drawing**으로 256px PNG 기반 `.ico` 파일을 만들고, 바탕화면 `.lnk`의 아이콘으로 지정합니다. 별도의 변환 프로그램 설치는 필요하지 않습니다.
- 아이콘 다운로드·변환에 실패해도 원본 엔진 설치와 로컬 생성 기능은 계속 이용할 수 있으며, 바로가기에는 일반 Windows 아이콘이 표시될 수 있습니다.
- **기존 바로가기나 기존 플러그인 폴더는 자동으로 덮어쓰지 않습니다.** 이번 과정은 신규 설치를 위한 코드이며 기존 설치의 자동 업그레이드는 후속 작업입니다.
- 아이콘의 이미지 제작과 코드 연결은 완료했지만 **Windows 실기에서 아이콘 표시/캐시/바로가기 실행 시험은 아직**입니다.

## v0.7 첫 실행·프롬프트 작업실·바로가기

- 첫 실행 화면은 **한글 3단계 안내**입니다. 작업별 사용법이 바뀌며, **사양 확인 버튼은 읽기 전용**입니다.
- 이 안내를 열었다고 AI 모델 다운로드·실행·GPU 설정 변경·GPT 연결이 자동 시작되지 않습니다.
- 바탕화면 바로가기는 **옵션**입니다. 실제로 `scripts\run.bat`가 있는 설치에서만 생성 시도를 하며 기존 `.lnk` 파일을 보호합니다.
- 공식 Manager 설치 방식과 바로가기의 실행 환경 연동은 **Windows 실기 검증 전**입니다. 문제가 생기면 공식 Manager의 **Start WanGP**로 실행할 수 있습니다.
- 원본의 전체 기능은 삭제하지 않지만 모든 모델의 가중치를 한 번에 설치하거나 저사양에서 모든 모델의 실행을 보장하는 뜻은 아닙니다.

### 무료 프롬프트 작업실 이용

1. 한글 탭의 **프롬프트 작업실**을 엽니다.
2. 제작 분야(영상/이미지/음성·음악/3D), 분위기, 시작 모드(기본 **절약**)를 선택합니다.
3. 만들고 싶은 내용을 적고 **무료 프롬프트 만들기**를 누릅니다.
4. **프롬프트 한 번에 복사** 버튼으로 문장을 복사합니다. 브라우저가 복사를 허용하지 않으면 직접 선택해 복사할 수 있습니다.
5. **원본 제작 화면 열기**로 이동해 복사한 문장을 원본 프롬프트 입력칸에 붙여넣고, **원본에서 모델과 설정을 직접 선택**하여 생성합니다.

이 도우미는 한국어 텍스트만 조합합니다. GPT/API를 호출하거나 GPU 작업·모델 다운로드를 시작하지 않습니다. 절약/균형/고품질은 **설명과 권장 순서**이지 원본 GPU 프리셋을 바꾸는 명령이 아닙니다.

## 설치 도우미가 하지 않는 것

- GPU 드라이버·Windows 설정 변경
- 기존 WanGP 소스·모델·사용자 파일 삭제 또는 강제 덮어쓰기
- GPT/Claude/유료 API 로그인 또는 자동 과금
- 모델 가중치 전부를 무조건 다운로드
- 인터넷에 사용자 사진·영상·토큰 업로드
- 검증에 실패한 설치 관리자를 실행

## 왜 공식 Manager를 사용하나요?

공식 WanGP Manager는 GPU에 맞는 환경과 실행 프로필을 안내하고 Python/의존성 설치, 버전별 업데이트·롤백을 지원합니다. 프로젝트 자체 installer를 새로 만들면서 원본의 드라이버/라이브러리 호환성을 훼손하지 않으려는 선택입니다.

다만 현재 공식 Manager는 **실험적(Experimental)** 윈도우 도구입니다. GPU 지원 여부는 원본 설치 문서를 확인해야 합니다.

## 처음 무료로 사용하기

- WanGP 기본 미디어 생성은 GPT 없이 로컬로 처리할 수 있습니다(호환되는 GPU·모델에 한함).
- `GPT 감독` 영역은 기본으로 꺼져 있습니다.
- 자동 영상 감독 Showrunner는 **Deepy Prime**이 필요한 별도 기능입니다. 로컬 LLM 또는 사용자가 선택한 원격 Codex로 이용하며, 어떤 방식이 가능한지는 PC 사양에 따라 다릅니다.
- 저사양 PC는 짧은 영상·낮은 해상도·소형 모델을 먼저 시험하세요.

## 문제가 생기면

| 현상 | 안내 |
|---|---|
| 공식 Manager 다운로드 실패 | 네트워크 확인. 공식 [Releases](https://github.com/deepbeepmeep/WanGP/releases)에서 직접 받을 수도 있습니다 |
| 체크섬 불일치 | 실행을 중단하는 것이 정상입니다. 다운로드 파일을 실행하지 마세요 |
| WanGP 폴더를 찾지 못함 | Manager에서 설치한 실제 폴더 경로를 입력하세요. `wgp.py`와 `plugins` 폴더가 있어야 합니다 |
| 한글 플러그인 이미 있음 | 기존 파일을 보호하려고 자동으로 중단합니다. 덮어쓰기/삭제하지 않습니다 |
| 바로가기 아이콘이 기본 아이콘으로 나옴 | 네트워크·PNG 검증 또는 Windows 변환이 실패했을 수 있습니다. 원본 Manager로 실행은 가능합니다. Windows 아이콘 캐시 적용은 실기 검증이 남아 있습니다 |
| 메모리 부족 | 다른 앱을 닫고 원본의 가벼운 모델·RAM/VRAM 프로필을 검토하세요 |
| GPU가 지원되지 않음 | 설치가 되더라도 일부 AI 모델은 실행되지 않습니다. 지원 기종 확인이 필요합니다 |
