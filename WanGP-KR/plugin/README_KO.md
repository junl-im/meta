## 사용 목적

- WanGP의 무료 로컬 미디어 생성 기본값을 유지한다.
- 코어 파일과 모델 처리/VRAM 최적화 코드는 수정하지 않는다.
- GPT/Codex/Deepy Prime 감독은 사용자 선택 항목이다. 초기에 꺼져 있다.
- 사용자에겐 완전 한국어 화면을 지향하고, 원본 UI로 돌아갈 수 있다.
- 새 UI는 SVG 파일·태그·SVG 데이터 URI를 사용하지 않는다. 전용 WebP 버튼 원화는 **로컬 파일을 CSS에 인라인 포함**하며 외부 CDN이 필요하지 않다.

## 가장 쉬운 적용 방법

원본 WanGP가 아직 없다면 **[Windows 전체 설치 안내](../docs/FULL_INSTALL_WINDOWS_KO.md)**를 먼저 이용하세요. `scripts/install_studio_full_windows.cmd` 파일 **하나만 받아 실행해도** 필요한 한글 코드 파일을 고정된 GitHub 버전에서 검증·다운로드한 후 공식 WanGP Manager를 실행합니다. 전체 엔진 설치가 끝나면 한글 플러그인을 추가합니다. 모든 모델 가중치를 무조건 받는 방식은 아닙니다.

## 수동 적용 방법 (개발자용, 아직 실행 전)

1. 공식 WanGP를 설치한다. 프로젝트 루트의 `scripts/bring_upstream.py`는 원본 소스만 가져오며 의존성 설치는 별도다.
2. `wan2gp-gomfox-studio/` 폴더 전체를 설치된 WanGP의 `plugins/` 아래에 **복사**한다.
3. WanGP를 재시작하고 **Apps & PlugIn Manager**에서 해당 앱을 활성화한다.
4. 새 탭에서 **원본 무료 제작 화면 열기**를 눌러 기존 미디어 생성 화면으로 이동한다.
5. GPT를 쓰고 싶을 때만 원본 Configuration에서 `Codex` + `Deepy Prime`을 구성하고 플러그인의 선택 감독 영역을 직접 연다.

## 한국어 홈 대시보드 (v0.16 개발판)

**v0.19 변경:** 네 WebP 카드의 원본 비율을 유지하고 왼쪽 글씨 대비를 높였습니다. 카드를 누르면 짧은 분야별 안내만 열리며 상세 설명은 기존 도움말 탭에서 확인합니다. 작업 현황 탭은 원본 큐를 한 번 조회해 전체·실행 중·대기 요약과 상세 내역을 나눠 표시합니다. 예시 배치 자료는 [v0.19 오프라인 미리보기](../docs/V019_VISUAL_PREVIEW.html)에 있습니다.

- 시그니처 PNG 배너·아이콘과 영상/이미지/음성/3D 독립 WebP 원화 버튼을 사용합니다. SVG를 쓰지 않습니다.
- 무료 제작·시작, 처음 실행·따라 하기, 프롬프트 작업실, 도움말, 모델 찾아보기, 작업 현황·갤러리, 저사양 안내, GPT 감독·선택의 **8개 화면**을 제공합니다.
- v0.16에서는 네 카드의 원화 크롭·2열 간격·한국어 자간·모바일 배너 높이를 다듬고, 카드 선택 전의 긴 도움말을 간결하게 줄였습니다.
- 영상·이미지·음성·3D 종류를 누르면 해당 작업의 기초 설명이 나오고, 원본 제작 열기 버튼으로 WanGP 생성 탭으로 이동합니다.
- **유의:** 작업 종류 버튼은 원본의 모델을 자동 선택하지 않습니다. 실제 모델은 원본 화면에서 고릅니다.
- 무료 기본 상태에서는 GPT 요청이 일어나지 않으며, GPU 설정도 자동 변경하지 않습니다.

## 현재 구현 범위

- 한국어 홈 및 기본 무료 로컬 모드 안내
- 클릭 시 WanGP 실행 PC의 RAM·GPU·가능한 VRAM을 읽는 **안전한 사양 확인 버튼**(설정 변경·외부 전송 없음)
- 처음 실행 탭의 **처음 시작하기 5단계** 도움말과 분야별 안내(사진·그림/짧은 영상/목소리·음악/3D/월드/저사양/GPT 선택/오류 해결/용어 풀이). 첫 탭에서는 분야별 카드를 누르면 짧은 안내만 나오고 긴 도움말은 별도 탭에서 확인
- 처음 실행 탭의 접이식 **문제가 생겼나요? 단계별 해결**에서 원본 실행·한글 탭·WebP 원화·모델 대기·파일 위치·무료 제작을 증상별로 선택할 수 있음. 안내 전환은 읽기 전용
- 도움말 선택은 정보 표시만 하며 모델 다운로드·GPU 작업·외부 감독 호출을 하지 않음
- 원본 미디어 생성 UI로 이동하는 버튼
- 원본 API `list_model_metadata()`를 직접 읽는 모델 목록·검색·분야 필터·페이지 기능(영상/이미지/음성/3D/월드/기타)
- 새로운 원본 모델은 원본 메타데이터에 따라 자동 표시하며, 하드코딩 화이트리스트를 두지 않음
- 기본 OFF인 선택 감독 영역 / 별도 동의 확인 / Deepy Prime 작업 호출
- 원본 모델·시드·큐·VRAM 처리 로직 직접 수정 **0건**

## 단위 테스트

메타 저장소를 내려받은 뒤 저장소 루트에서 실행:

```bash
python -m unittest discover -s WanGP-KR/tests -v
```

이 테스트는 Gradio·WanGP·GPU가 없어도 **모델 탐색·도움말·하드웨어 보고서·모의 UI 이벤트·이미지 파일·안전 설치 계약**을 점검한다. **원본 앱에 플러그인을 설치한 Windows 통합 테스트는 별도이다.**

## 아직 구현하지 않은 것

- GPU 및 VRAM 자동 탐지와 실제 설정에 적용되는 세 단계 성능 모드 (현재는 안내만 지원)
- 원본 WanGP 실제 실행 환경에서의 모델 탐색기 동작 확인
- 모든 원본 UI 텍스트의 한글 번역
- Showrunner의 전체 한국어 통합/자동 편집
- ChatGPT 대화창에서 MCP로 직접 연결
- 자동 배치·복구·미디어 갤러리 전용 UI

실제로 설치해 실행하기 전에는 **정상 작동·성능 동등성·원본보다 우수함**을 주장하지 않는다.
