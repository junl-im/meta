# 곰같은여우의 AI 스튜디오 — 초기 한국어 플러그인

**개발 버전 0.4.0-dev. 실제 WanGP 구동 환경에서 미검증.**

## 사용 목적

- WanGP의 무료 로컬 미디어 생성 기본값을 유지한다.
- 코어 파일과 모델 처리/VRAM 최적화 코드는 수정하지 않는다.
- GPT/Codex/Deepy Prime 감독은 사용자 선택 항목이다. 초기에 꺼져 있다.
- 사용자에겐 완전 한국어 화면을 지향하고, 원본 UI로 돌아갈 수 있다.
- 새 UI는 SVG 파일/태그/데이터 URI를 사용하지 않는다.

## 적용 방법 (아직 실행 전)

1. 공식 WanGP를 설치한다. 프로젝트 루트의 `scripts/bring_upstream.py`는 원본 소스만 가져오며 의존성 설치는 별도다.
2. `wan2gp-gomfox-studio/` 폴더 전체를 설치된 WanGP의 `plugins/` 아래에 **복사**한다.
3. WanGP를 재시작하고 **Apps & PlugIn Manager**에서 해당 앱을 활성화한다.
4. 새 탭에서 **원본 무료 제작 화면 열기**를 눌러 기존 미디어 생성 화면으로 이동한다.
5. GPT를 쓰고 싶을 때만 원본 Configuration에서 `Codex` + `Deepy Prime`을 구성하고 플러그인의 선택 감독 영역을 직접 연다.

## 현재 구현 범위

- 한국어 홈 및 기본 무료 로컬 모드 안내
- 클릭 시 WanGP 실행 PC의 RAM·GPU·가능한 VRAM을 읽는 **안전한 사양 확인 버튼**(설정 변경·외부 전송 없음)
- 기본으로 펼쳐지는 **처음 시작하기 5단계** 도움말과 분야별 안내(사진·그림/짧은 영상/목소리·음악/3D/월드/저사양/GPT 선택/오류 해결/용어 풀이)
- 도움말 선택은 정보 표시만 하며 모델 다운로드·GPU 작업·외부 감독 호출을 하지 않음
- 원본 미디어 생성 UI로 이동하는 버튼
- 원본 API `list_model_metadata()`를 직접 읽는 모델 목록·검색·분야 필터·페이지 기능(영상/이미지/음성/3D/월드/기타)
- 새로운 원본 모델은 원본 메타데이터에 따라 자동 표시하며, 하드코딩 화이트리스트를 두지 않음
- 기본 OFF인 선택 감독 영역 / 별도 동의 확인 / Deepy Prime 작업 호출
- 원본 모델·시드·큐·VRAM 처리 로직 직접 수정 **0건**

## 단위 테스트

메타 저장소를 내려받은 뒤 저장소 루트에서 실행:

```bash
python -m unittest discover -s WanGP-KR/tests -v
```

이 테스트는 Gradio·WanGP·GPU가 없어도 **모델 탐색·도움말·하드웨어 보고서 형식**을 확인한다. 개발 환경에서는 소스 코드 AST 파싱과 핵심 동작 검사 7개를 통과했다. **원본 앱에 플러그인을 설치한 통합 테스트는 별도이다.**

## 아직 구현하지 않은 것

- GPU 및 VRAM 자동 탐지와 세 단계 성능 모드
- 원본 WanGP 실제 실행 환경에서의 모델 탐색기 동작 확인
- 모든 원본 UI 텍스트의 한글 번역
- Showrunner의 전체 한국어 통합/자동 편집
- ChatGPT 대화창에서 MCP로 직접 연결
- 자동 배치·복구·미디어 갤러리 전용 UI

실제로 설치해 실행하기 전에는 **정상 작동·성능 동등성·원본보다 우수함**을 주장하지 않는다.
