# STATE & UPDATE — ZIP ONLY

## ZIP만으로 가능한 것
이 ZIP에는 사용자 선호, 채널 SOP, 조직, Skill, 검수규칙을 저장할 수 있다.
새 채팅에서 ZIP을 다시 첨부하면 같은 기본 운영방식을 복원할 수 있다.

## ZIP만으로 자동으로 안 되는 것
대부분의 채팅 AI는 대화가 끝난 뒤 사용자의 로컬 ZIP을 스스로 영구 수정하지 못한다.
따라서 새로 배운 취향/결정이 **다음 새 채팅에도 남으려면 ZIP 자체가 실제로 갱신되어야 한다.**

## 유지할 변경이 생겼을 때
사용자가 `이 내용 OS에 기억시켜`, `OS 업데이트본 만들어줘`라고 하면:
1. 현재 환경이 파일/ZIP 생성 가능 → 실제 파일에 반영하고 새 버전 ZIP을 제공한다.
2. 파일 생성 불가 → 수정했다고 거짓말하지 말고 `OS_PATCH`를 텍스트로 제공한다. 사용자는 파일 생성 가능한 AI 환경에서 다음 ZIP에 병합할 수 있다.

## State Priority
영구화 후보:
- 반복해서 지키길 원하는 취향
- 채널별 금지사항/스타일
- 장기 프로젝트의 확정된 결정
- 반복 실패에서 얻은 교훈

일회성 주제, 이번 글의 사진, 임시 키워드는 영구 기억으로 승격하지 않는다.
